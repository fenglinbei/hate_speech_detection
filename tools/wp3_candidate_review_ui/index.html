原文标注指南

            
A / B / C 暂定收录口径

          

          
        

        

          一句话记忆：A 可以稳定讲清；B 必须结合上下文；C 目前还不能可靠讲清。
          
这里的 A/B/C 是 mention 的暂定证据分流，不是质量分、任务类别或当前句子的结论。后续补证据和诊断仍可改变分流。

        

        

          
共同前提：先确认值得收录

          
    
            
  • 原文中有可重放的精确 occurrence，边界是最小且语义自足的连续单位。
    • 
            
  • 确有非平凡解释缺口；不了解特殊写法、网络义、典故或语用时会看不懂或误解。
    • 
            
  • 只解释表达本身，不依据任务标签，也不替当前文本作分类判断。
    • 
          

        

        

          

            A
            
稳定核心候选 A_candidate

            
精确表达可以稳定对应同一条有依据的核心释义，并且跨 occurrence 仍适用。

            
    
              
  • 核心含义或形式转换已有可追溯支持。
    • 
              
  • 没有未解决的主要替代义或关键反例。
    • 
              
  • 能够写成中性词义，不夹带任务裁决。
    • 
            

            
典型：txl、舔狗 在映射和稳定义均有证据时。

            
默认原因：稳定核心释义候选

          

          

            B
            
需上下文候选 B_candidate

            
表达确有解释价值且至少一个 sense 有支持，但不能安全压成一个无条件定义。

            
    
              
  • 普通义与网络义并存，或存在多个受支持解释。
    • 
              
  • 语气、讽刺、立场、引述、讨论或回收用法会改变解释。
    • 
              
  • 必须依据当前原文的可观察线索选择 sense。
    • 
            

            
典型：基佬、666、呵呵 等需判断具体用法。

            
默认原因：需要结合上下文

          

          

            C
            
待核实候选 C_candidate

            
表达可能有真实解释价值，但目前不足以可靠决定 A、B 或排除。

            
    
              
  • 具体含义、标准形式、变体关系、形成机制或边界仍未解决。
    • 
              
  • 证据不足、相互冲突，或无法判断是稳定用法还是一次性创造。
    • 
              
  • 只记录明确未知点；没有独立支持时不能猜写具体释义。
    • 
            

            
典型：幕刃、郭女 等映射或变体关系尚待证实。

            
默认原因：需要补充证据

          

        

        

          
不要把明确噪声塞进 C

          
透明普通词、普通身份或名称、通用辱骂、语法碎片、带入功能词、完整句、错误 substring、非 fit 表达应排除为 R。例如 女拳不 是碎片，普通指称的 黑人 没有额外解释缺口。

          
互斥判断顺序：不是资源对象 → R；有价值但证据未决 → C；含义成立但需上下文 → B；全部稳定门槛通过 → A。
