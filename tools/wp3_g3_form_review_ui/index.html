G3 形式关系审核指南

            
只审核冻结证据支持的形式关系

          

          
        

        

          一句话记忆：判断“这个 surface 是否是该 canonical 的这种形式变体”，不要判断词义、态度、类别或任务标签。
          
handbook 仅提供审核规则，不能单独证明关系。页面中的公开材料快照才是本轮可以使用的证据。

        

        

          
共同证据门槛

          
    
            
  • surface 与 canonical 必须能在所选冻结证据中逐字重放，并且材料确实陈述或展示二者的形式关系。
    • 
            
  • 一次决定只能使用同一公开来源；采用 v2 单引文契约时，二者还必须位于同一冻结 component/quote。
    • 
            
  • 相同词对来自不同来源时仍逐项独立审核，不合并，也不因另一项已通过而自动接受。
    • 
            
  • 不要补写定义、证据分档、冒犯性、立场、任务类别、record ID 或任何训练标签。
    • 
          

        

        

          

            1
            
接受 accept

            
原 surface、canonical、family、scan 设置和证据选择均正确，冻结材料足以支持该形式关系。

            
接受会原样保留提案字段。

          

          

            2
            
修订 edit

            
材料支持一条形式关系，但提取的 surface、canonical、family、scan 或证据选择需要修正。

            
至少修改一个提案字段，且修订结果必须在同一冻结证据中重放。

          

          

            3
            
驳回 reject

            
不是有效形式关系、证据不足、把语义关系误当形式关系，或提案提取错误且无法由当前证据修正。

            
驳回仍原样保留提案字段，判断原因写入备注。

          

          

            4
            
暂缓 defer

            
当前确实无法决定时临时搁置。defer 不是完成结论，reference finalize 前必须全部重新打开并清零。

            
请在备注中写明待解决问题。

          

        

        

          
三种 family

          
    
            
  • known_variant：公开材料明确给出的既有书写或约定变体。
    • 
            
  • phonetic_variant：拼音首字母、谐音或近音等语音形式关系。
    • 
            
  • orthographic_variant：字形替代、拆合或其他明确的书写形式关系。
    • 
          

        

        

          
确认、锁定与更正

          
草稿会自动保存；“确认并继续”后该项锁定。更正已确认项必须点击“重新打开”，填写 amendment reason 后再修改。不要在多个页面同时编辑同一 session；若发生 CAS 冲突，页面会要求明确选择服务器版本或重新应用本地决定。
