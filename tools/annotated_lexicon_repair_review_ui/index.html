判断口径 · 操作指引
先判断是否需要解释，再核对精确边界

        

          
本轮标注合格的解释对象，不标注整句话是否仇恨。
保留 = 修复后的 matcher 应返回此处的 span。删除 = 此处不应提供词典解释；不等于从词典全局删除这个词。

          
当前义项决定保留与否

            

              
删除
普通义项，不属于目标解释用法
即使边界正确、多义词也确实存在，只要当前义项无关，就删除此处 span。
例：“各位同志辛苦了”中的“同志”不是词典所指的同性恋义项。“它们”若只是普通指代，也不应仅凭词面保留。

              
保留
目标义项成立，句子未必有恶意
引用、反驳、支持或反对歧视，不会自动使解释对象失效。
例：“不要歧视同性恋同志”中的“同志”义项匹配，应保留。普通义项 ≠ 非仇恨语境。

              
保留 + 备注
应该解释，但释义错误或漏收义项
保留合格的 span，在备注写清当前用法与释义问题，留到后续修复；不为扩充普通词义而保留无关命中。
例：“用粤语屌他”中的“屌”应解释为此处的骂人用法，不能只给出生殖器义。

            

          

          
边界与 occurrence
  • 同词在同一句出现多次，每个位置分别判断。边界或词义不匹配的候选应删除。
  • 最终保留项不得重叠；“妈宝女 / 妈宝”“寄生虫 / 虫”只保留最长且合格的一项。
  • 如果候选边界错误，应删除旧候选；缺少正确候选时，再划词补充精确片段。
  • 若所有候选都不合格，可全部删除并确认；没有候选且没有遗漏时，可直接确认。

          
发现遗漏：划词 → 确认 → 写理由
在开发查询原文中选中片段，点击“确认片段”，核对后填写理由并加入。页面自动计算字符位置，区分同词的不同 occurrence，保留原文字符。已知遗漏已列为候选，不要重复加入；新增项可修改理由或移除。

↑ / ↓
