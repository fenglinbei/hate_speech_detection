精确 span 审核说明
每张候选卡对应查询中的一个字符区间。选择“保留”表示 repaired matcher 应返回该 span；选择“删除”表示该位置不应作为词典解释资源。
同一句中不同 occurrence 必须分别判断。最终保留 span 不得重叠；例如“妈宝女/妈宝”“寄生虫/虫”只保留最长且合格的一项。已知遗漏已直接列为候选，不需要重复填入额外 span。
额外 span 仅用于发现候选清单之外的新遗漏，start/end 使用 Python Unicode 字符索引、左闭右开。
