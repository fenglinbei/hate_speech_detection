第 1 步 · 四项资源初读怎么写先读查询，再看词典和示例

中间是材料，右侧是记录。围绕标题所示的重点任务阅读：仇恨判断看整句话的表达与立场；目标群体看所针对的群体类别。每项写一两句话，并指向具体措辞、词条或示例。

“查询命中”指查询匹配到的词条；“仅示例带入”指查询未命中、但固定示例匹配到的词条。匹配到词不保证词义适用。“冻结”表示本轮材料保持原样，发现问题写进复核记录。

“雾谷”及其居民是虚构的。例子只演示如何写观察，不预设真实案例的立场、标签或用途。

什么时候继续：四项都有记录后，点“保存初读 · 查看轨迹”。没有相关词条可写“无相关词条”；缺信息要写清缺什么。最初观察会固定保存，后来的修正放在第二步理由或解释中。

第 2 步 · Gold、六条件和分数怎么看先比较预测，再读分差；不必计算公式

Gold = 数据集原有的参考答案。表中“正确”只表示与它一致；你可以记录不同看法。目标群体任务要整组标签一致才算正确，“无目标群体 ∅”表示空集合。

六条件 = 同一句查询，给模型搭配六种材料。所有条件都有相同的基础任务提示和查询。S 表示词条与释义，G 表示词典中显式写出的类别，D 表示固定示例及其答案；NoCat 就是删去 G。

简称附加给模型的材料
0不加词典或示例
SG词条、释义 + 显式类别
D示例正文 + 示例答案
SGD含类别词典 + 示例与答案
S词条、释义，删去显式类别字段
SD去类别词典 + 示例与答案

词典词条取自查询和固定示例的命中并集，所以 S 中也可能有“仅示例带入”的词条。删除类别字段后，释义或示例里仍可能包含群体信息；示例答案也保留。

按这个顺序读：先看 0 → S、0 → D、D → SD，知道加资源后预测有没有变；再比较 SG → S、SGD → SD，知道删除类别字段后怎样变化。需要确认模型究竟看到了什么时，点“完整提示”。

Gold margin · 原答案的领先分差
Gold 的分数 − 得分最高的其他答案。正数：Gold 领先；负数：其他答案领先；精确为零：并列。数值增大表示相对更支持原 Gold，即使预测还没有变。
Top gap · 前两名分差
得分第一名 − 第二名。越接近零，两者越接近；第一名也可能是错误答案，所以分差大不代表答对。
这些分数的单位
主表按候选答案各 token 的对数概率相加计分。margin 和 gap 都是分数差，不是正确概率，也不是百分比。页面保留三位小数，0.000 可能只是舍入。
计分口径敏感 / 近并列
口径敏感指换成平均分或计入结束符后，选中的答案会改变；近并列指前两名差距很小。遇到这些提示，先考虑是否需要核验计分再作解释。
提示 tokens · 输入长度
模型切分后的输入单位数量，近似反映提示长度，不等于汉字数。删字段也会改变长度和后文位置，这可能成为替代解释。

虚构分数示例

假设 Gold 为 A：某条件下 A 得 −2 分、B 得 −3 分，margin = +1，Top gap = 1；另一条件下 A 得 −4 分、B 得 −2 分，margin = −2，Top gap = 2。后者第一名领先更多，但选中的是 B，与 Gold 不一致。

表下四张卡：前三张显示两个条件的 margin 差；第四张是“已有示例时加词典”的变化减去“没有示例时加词典”的变化，即 SD − S − D + 0。它们帮助描述变化，不能单凭正负号认定原因或证明模型内部机制。

第 3 步 · 两种解释、输入对照和用途写观察到什么，再写如何分辨原因

先判断原 Gold：“认可”表示符合你的理解；“有争议”表示你有具体依据支持不同答案；“信息不足”表示缺少判断所需的信息。后两项必须写理由。围绕本例重点任务填写，另一任务的发现可以作为补充注明。

候选解释：你目前更倾向的原因
写“哪两个条件发生了什么变化 → 哪段资源可能导致这种变化”。把观察和猜想分开，避免仅写“模型理解错了”。
替代解释：同一变化也可能怎样产生
提出与候选解释竞争的另一种原因。它不是另一个仇恨/群体标签，也不是把候选解释换句话重复；要能说明为什么现在还不能确定原因。
输入对照：改一点输入，再比较结果
给后续实验写方案：改什么、保持什么、观察什么，以及哪种结果会反驳候选解释。在当前工作台只记录方案，确认用途不会启动实验。

虚构解释与对照示例 · 不是本轮结果

假设观察：SGD 答错，SD 答对。

候选解释：我猜显式类别字段把模型带向了错误的群体判断；删掉它后，模型更多依据查询中的反对立场。

替代解释：也可能是删除字段缩短了提示、改变后文位置，而非类别含义本身起作用。

输入对照：将类别内容换成同位置、等 token 长度的中性占位内容，保持查询、释义、示例及其顺序不变。比较原类别、等长占位、直接删除三版的预测和 margin。若等长占位仍像原类别版一样答错、只有删除才改善，就削弱“类别含义是主因”的猜想，需要继续检查长度和位置。

用途按当前能推进到哪一步选择，三项都是有效复核结论：

1 · 进入输入对照

有具体待检验解释，也能写出可区分解释的方案；关键 Gold、上下文和计分疑问已处理，或可清楚限定对照如何解释。必须填写“下一步输入对照”。选中只表示准备继续检验，不代表原因已证实。

2 · 先核验再使用

案例值得继续，但有一个可指出、可先检查的问题，例如计分口径敏感，或需核对原始上下文才能判断 Gold。原因里写“先查什么，查清后才能决定什么”。

3 · 暂缓使用

目前无法提出清楚、可行的对照，或材料缺失使下一步难以推进。原因里写具体卡在哪里。拿不准解释时可明确写“暂无法形成候选解释 / 暂无法区分替代解释”，不用编一个结论。

最后：Gold 判断、候选解释、替代解释和用途都要填写；选“输入对照”补方案，选“先核验 / 暂缓”补原因。然后点“确认并继续”。
