# 通用模型词典与示例机制实验正式协议 v1

日期：2026-09-04（Asia/Shanghai）。协议标识：`general-model-ld-mechanism/v1`。

**状态：研究决策已通过本轮 Q1–Q16 访谈确认；已进入 dev 运行包构建。** 本文件确定研究对象、任务、数据边界和证据要求；工程配置、构建结果和待办以[运行包说明](general-model-ld-run-package-v1.md)及其 readiness 为准。dev 包不等于正式 test 运行授权。

## 1. 优先级与研究目标

本协议是当前固定资源机制研究的主协议。它在本阶段取代[六阶段总计划](causal-context-six-stage-plan.md)和[旧 Stage1 P0 规格](stage1-p0-implementation.md)中关于任务主次、必需微调模型、完整四字段门槛、category-free 主资源和选择器交付的要求。旧文档与产物保留为历史方案和工程参考。

核心问题是：在同一冻结通用模型上，词典 L 与检索示例 D 如何影响仇恨判断和数据集类别判断；这些影响来自定义语义、类别提示、示例对应关系、标签、格式还是位置；证据冲突和具体错误能否通过输入及内部干预解释。

- **分类是主任务**：句级仇恨二分类、句级数据集类别多标签分类，分别提示、分别输出和评分。
- **提取是副任务**：辅助观察 target、argument 及关系绑定，不以完整四元组正确率作为统一进入门槛。
- **当前目标是机制证据**：不要求最终 F1 提升，不要求不同模型出现相同机制，也不要求 L/D 一定有益。
- **后续任务**：任务微调、上下文利用方式改进、因果效用选择器和路由器，待通用模型结论稳定后另立协议。
- **范围**：先在当前一版中文数据集上验证指定模型。新独立数据集上的泛化验证不是本阶段完成条件。

用户选择分类为主，是考虑到旧试验的提取困难和数据质量限制。这是研究优先级决定，不等于已证明所有分类金标准确；既有标注局限仍须保留。

## 2. 研究模型与运行边界

“通用模型”指未经过本项目仇恨检测任务微调的模型，允许通用指令训练和后训练。项目目录名 `models/base` 不表示模型一定是纯预训练 Base。

| 官方模型 ID | 本阶段分工 |
| --- | --- |
| `Qwen/Qwen3-8B` | 主模型，完整行为干预分析及少量内部干预。 |
| `Qwen/Qwen3-14B` | 同代不同规模复验，运行预先确定的核心对照。 |
| `Qwen/Qwen3.8-27B` | 跨代、跨架构复验，运行预先确定的核心对照。 |

本阶段不纳入 Qwen3-4B、Qwen2.5-7B-Instruct 或其他模型，不训练 `M_LD`、`M_drop`，不继承旧计划的三组训练 seed 要求。

三种模型均支持关闭显式思考；主实验统一关闭，直接输出当前任务答案，并冻结各模型的解码设置。开启思考属于后续独立实验。Qwen3.8-27B 是具有视觉编码器、采用 Gated DeltaNet/Gated Attention 混合结构的模型，本实验仅提供文本输入。因此三模型差异不能全部解释为参数规模效应。[Qwen3-8B 官方说明](https://huggingface.co/Qwen/Qwen3-8B)、[Qwen3-14B 官方说明](https://huggingface.co/Qwen/Qwen3-14B)、[Qwen3.8-27B 官方说明](https://huggingface.co/Qwen/Qwen3.8-27B#model-overview)（本轮核查日期同上）。

目前已有 Qwen3-8B 本地生成及 logprob 运行基础；14B、27B 的实际接入和运行验证仍待完成。存在 API 配置不代表服务身份、logprob 或内部 activation 访问已验证。运行前须记录准确模型版本或权重哈希、tokenizer、chat template、后端、精度、思考开关及解码配置；同模型的成对条件保持一致。

内部干预先集中于 8B，不要求将 27B 的不同架构内部组件直接对应到 Qwen3。复验条件在查看相应 test 结果前固定，不依据某模型效果选择性补跑或删除条件。

不同任务共享示例身份，但模型可见的示例答案不同。因此跨任务差异反映整套任务设置差异，不能全部归因于输出提取负担。两种分类任务独立提供各自答案；查询 gold 不进入模型提示。

## 5. 主分类任务与辅助提取

### 5.1 句级仇恨二分类

对冻结 gold 中的所有四元组：

```text
gold_hate(x) = hate      if any(tuple.hateful == "hate")
               non-hate otherwise
```

输入数据已完成缺失/异常裁决；上述 otherwise 仅针对合法、完整的 gold。未知值或解析失败不能转成 non-hate。混合仇恨与非仇恨状态的句子按 any-hate 投影；不得从 group、词典类别或提取结果推导该任务答案。

### 5.2 句级数据集类别多标签分类

```text
gold_groups(x) = union(tuple.targeted_group for all gold tuples) - {"non-hate"}
label_space = {"Racism", "Region", "LGBTQ", "Sexism", "others"}
```

保留所有 tuple 的类别，包括已裁决保留的“具体 group + non-hate”组合；不先按 hate 过滤，不仅取第一个 tuple，不强制单选。`[]` 是有效答案，表示原数据未标注上述任务类别，与缺失输出、解析失败区分。

该任务预测**现有数据集的类别集合**，不等于识别句中所有被提及或被指向的真实群体。旧标注对中性群体提及的覆盖并不完整，去掉 non-hate 不会生成缺失的群体金标。两个分类任务的提示和输出独立，不代表数据语义或模型内部通路已经解耦。

### 5.3 辅助提取

保留 target、argument、targeted_group、hateful 的字段含义，但放宽输出格式、非精确跨度和字段完整性。使用预先固定的恢复、匹配与评分规则，合法字段独立计分；缺失字段记为未回答，不使其他可评分字段整体失效。

缺失、格式恢复、跨度近似匹配分别记录。报告固定样本分母上的字段表现与覆盖率，不只报告成功输出子集。不得利用 gold 补全预测，或用 group 补 hateful。gold 中合法的显式 null 与预测字段缺失须区别处理。

现有严格四字段 parser、整条失败处理和旧 group-to-hate 推导不能直接作为新任务入口；需实现独立的分类投影和宽松提取评分适配。完整 tuple F1 仅作适用范围内的辅助读数，不能成为主分类实验的进入或成功条件。

## 6. 机制研究顺序与对照原则

原总计划的前五阶段保留为研究路径，围绕两个分类任务重排；提取结构分析在辅助任务中开展。

| 阶段 | 本阶段工作与证据 |
| --- | --- |
| 来源效应 | 同模型、同查询比较 C0、CL、CD、CLD，并用 PL/PD 控制额外上下文形态与长度。 |
| 信息分解 | 词典定义/类别分离、类别交换、定义替换和语义等价改写；示例输入/标签/格式分离、对应关系打乱及位置干预。 |
| 冲突仲裁 | 根据有效材料区分语义冲突与标签冲突，观察 L/D 来源支配与组合效应。 |
| 实例归因 | 对固定已选词条/示例做 leave-one-out、add-back 及有限交互分析，定位有益、有害和字段分歧。 |
| 内部干预 | 从 dev 的可重复行为差异中选少量配对，在 8B 上进行 activation patching 和组件消融，检验恢复与破坏效应。 |

基础条件含义固定为 C0 无 L/D、CL 仅 L、CD 仅 D、CLD 同时有 L/D、PL 仅匹配词典形态的中性对照、PD 仅匹配示例形态的中性对照。它们分别用于两个主分类任务。原资源、删除条件和干预条件共享查询身份；不能删除一类资源后把腾出的预算用于另一类资源。

完整可执行条件清单属于后续运行注册，不能把以上研究路径当作所有条件已构建。清单须明确各模型/任务/样本帧的覆盖、主比较和依赖。PL/PD 长度匹配、换序、删除造成的位置变化，均须进入构造记录和相应解释边界。

多义项、多类别词条必须先确定干预单位和 donor 规则；7 个空释义项作为事前可识别切片，不能当作完整定义证据。标签 shuffle 须记录实际标签是否改变；仅换 donor ID 不一定构成有效标签腐化。

定义敏感性、标签跟随和结构迁移各需相应对照。仅有正确定义条件的高分、attention 可视化或 probe 准确率，不足以确立内部因果机制。内部干预不要求重建完整回路；只报告获得证据的路径，未形成稳定配对的路径保留为未解决。

## 7. 评分、稳定性与报告边界

主要证据来自两个分类任务，至少分别保留预测标签、分类表现、错转对/对转错、来源主效应和交互效应。概率或 margin 读数作为机制诊断，与最终标签行为分开报告；辅助提取单列。

概率比较固定模型、任务、标签编码和比较族；多标签 group 的正确/反事实编码必须与新任务匹配。不能沿用旧 pilot“只改第一个 tuple 的 group/hate、比较完整 JSON completion 总 logprob”来冒充当前独立分类评分，也不能直接比较不同 tokenizer 或字段的 raw margin 大小。

指标名称、主次 endpoint、标签编码、foil、置信区间、多重比较、有效样本与缺失处理，须在 dev 开发后写入运行注册，在新 test 输出前冻结。旧 P0 的四字段、训练 seed 和正向收益 gate 不自动继承。

稳定性要求如下：

1. 同模型固定输入与设置的行为可重放；解码、批形状及数值差异经工程检查。
2. 相应对照支持所声称的解释，统计不确定性、材料覆盖和失败范围可查。
3. 自由生成标签变化、概率偏好变化、内部干预效果分别限定证据层次。
4. 8B、14B、27B 结果不同可作为模型边界；不因不一致反复修改实验直至一致。
5. 正效应、负效应、未检出效应均可报告；未检出不等于已经证明零效应。
6. 不以总体 F1 提升、所有模型一致或所有机制路径均成功作为完成要求。

按 query 配对比较并保留同一主样本帧。无词典命中、group 空集、模型未回答和基础设施缺测是不同状态，不能静默取成功交集。全 test 与约 300 条机制子集分别报告；各模型是固定研究对象，不充当三个独立训练 seed。

## 8. 新干预材料的有限盲审

标签交换、示例删除等机械干预自动核验。定义语义等价改写、立场反转等语义操作接受有限盲审，检查预期含义是否成立以及非目标信息是否保持；审核者不看实验模型输出。

盲审只面向新构造的干预材料，不重开词典修复或整份数据集标注。具体数量、审核者/辅助模型、分歧处理与替换规则在材料构造前固定；test 材料只能在冻结政策下物化和审核，不能借审核改动主政策或既有 gold。
