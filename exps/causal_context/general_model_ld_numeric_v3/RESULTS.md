## 1. 阻断如何解决

采用父协议预注册的真实 batch 1 后备路径，四张 L20 各运行相同 FP32 模型副本。原 batch 4 的 numeric-03 仍为失败，不将其改判，不混用旧分数，不修改输入、候选、统计口径或数值容差。

沿用原 `E8=0.00067138671875`、`epsilon=0.0013427734375`。原 8 条及已暴露的 24 条共 12 个后备预检 pass 全部通过，最大差 `0.0010089874267578125`。本版验收的是重复、CPU 算术参考及 padding、逐前缀参考、候选执行顺序、跨物理卡四类适用挑战；不声称原 batch 4、尾批和批内位置检查通过，也不把 24 条称为新未见验证集。

完整 dev 为 **643 条 query、7,716 个条件记录、131,172 个候选、1,080,240 个答案 token**。原始分数全部封存后才关联 query gold；未读取 test。四个 GPU worker 已正常退出，运行终态为 `complete`。

## 2. L/D 将偏好推向哪里

L 是当前 query 命中的冻结词条内容，D 是固定检索示例。主分数为完整答案段总 logprob，不含 EOS；hate 使用两候选分差，group 使用 32 个规范集合上的标签边际 log-odds。每条 query 等权。正变化表示向 hate 或向包含该 group 标签的集合移动，不等于答案已经选该类，也不等于更正确。

下表为全部 24 项主结果的均值 [逐项描述性 95% CI]，单位为注册 margin 的自然对数尺度。`L=CL-C0`，`D=CD-C0`，`LD=CLD-C0`，`LxD=CLD-CL-CD+C0`。

| 读数 | L | D | LD | LxD |
| --- | --- | --- | --- | --- |
| hate | +0.975 [0.804, 1.152] | +7.071 [6.775, 7.369] | +6.926 [6.623, 7.235] | -1.120 [-1.311, -0.933] |
| Racism | -1.488 [-2.184, -0.793] | +2.330 [1.382, 3.274] | +1.676 [0.584, 2.753] | +0.835 [0.308, 1.370] |
| Region | -1.588 [-2.180, -1.001] | +3.375 [2.502, 4.256] | +2.095 [1.120, 3.067] | +0.309 [-0.198, 0.820] |
| LGBTQ | -1.411 [-1.993, -0.836] | +0.582 [-0.195, 1.361] | -0.477 [-1.355, 0.396] | +0.351 [-0.119, 0.839] |
| Sexism | +0.683 [0.036, 1.339] | +7.636 [6.703, 8.561] | +6.877 [5.844, 7.887] | -1.442 [-2.046, -0.858] |
| others | -0.729 [-1.415, -0.037] | -0.956 [-1.677, -0.218] | -0.439 [-1.357, 0.495] | +1.246 [0.775, 1.712] |

**hate：D 的正向推动最清楚，L 的增量依赖是否已有 D。** C0 的平均 margin 为 -6.421，CL 为 -5.446，CD 为 +0.651，CLD 为 +0.506。D 的变化在 97.5% query 上超出正向数值分辨带，但这不是 97.5% 的分类准确率。单独 L 为正，在已有 D 时再加 L 却为 -0.145 [-0.232, -0.056]；组合低于两者变化之和。四种计分口径下，hate 的 L/D/LD 正、LxD 负方向一致。

**group：主总分显示标签特异的移动，不能概括为统一增强。** D 对 Sexism 的总体平均推动最大；对 Racism、Region 为正，对 others 为负，LGBTQ 的 D 区间跨零。L 对四桶为负、Sexism 为正，但这些判断必须附带下节的计分和大小限制。CD 下五桶的平均 margin 水平仍全部为负，平均移动不能替代逐 query 的包含概率、最终选择或多数票判断。

**聚合尺度也重要。** 上述方向特指平均配对 log-odds。相同答案总分下，L 对五桶平均包含质量的变化却全部为正：Racism +0.00149、Region +0.00801、LGBTQ +0.01473、Sexism +0.04857、others +0.05031；D 对 others 的平均包含质量也为 +0.03389。这与主 margin 结果并不矛盾，因为先取逐 query log-odds 再平均，不等于先平均概率后取 log-odds。不能将主结果改述为“四桶的总体平均概率下降”，也不据此替换已注册主端点。

**非加性不是内部机制识别。** hate/Sexism 的主交互为负；Racism/others 为正；Region/LGBTQ 的交互区间跨零。正交互不表示 L、D 都有正效应，也不自动表示协同。完整四项辅助比较见[审计后导出报告](results/numeric-04/REPORT.md)；例如 CD-PD 对 Racism 为 -3.788、Region 为 -4.527，而 CD-C0 为正，说明结论也依赖所问的对照。PL/PD 只是近似形态和长度控制，不是净语义、净标签效应的充分隔离。

## 3. 词典暴露与主总体

223 条 query 命中词典，420 条未命中。未命中时 C0/CL、CD/CLD 的对应输入相同；实际四种计分、六个 margin 的逐 query L、L|D、LxD 均精确为 0。这是没有 L 暴露时的设计结果，不能当成 420 次“词典机制无效”的独立证据。

主总体仍保留全部 643 条，因此总体 L 均值等于命中层 L 均值乘以 223/643。命中层 hate 的 L 为 +2.811 [2.403, 3.213]，交互为 -3.229 [-3.646, -2.789]。D 的分层差异也不能忽略：Region 的 D 在命中层为 -0.517 [-2.115, 1.096]，未命中层为 +5.441 [4.429, 6.452]；不能将总体方向直接推广到每个切片。

## 4. 计分与集合大小限制

**EOS 不是本轮总分方向差异的主要来源。** 全部八项比较、六个 margin、643 条 query 中，含/不含 EOS 总分的配对变化最大差约 0.000454，小于对应经验数值带；24 项总体主均值最大差约 9.87e-7。[逐 query 核验回执](audits/numeric-04-closeout.json)记录了原分析字段、完整 jq 复算式及最大差位置（query 6993、group/LGBTQ、LD），共核对 30,864 项配对读数。此处比较的是两种总分，不能把 token 均分的分母变化叫作 EOS 本身的贡献。group 的 logsumexp 非线性，也不能将 EOS-only margin 当成可加差额。

**长度归一化会改变多个 group 方向，主总分不因而被替换。** L 对 Racism/Region/LGBTQ/others 的总体点估计在答案总分下为负、token 均分下均为正。例如 LGBTQ 的 L 从 -1.411 [-1.993, -0.836] 变为 +0.088 [0.030, 0.151]。D 对 Racism 从 +2.330 [1.382, 3.274] 变为 -0.099 [-0.190, -0.007]；others 的交互从 +1.246 [0.775, 1.712] 变为 -0.049 [-0.089, -0.012]。均分口径改变了读数尺度，其归一化质量是偏好权重而非序列概率，不能直接比较两种幅度。

**集合大小分配同时发生变化。** 以下为答案总分下的描述性均值，无新增 CI；equal-k 仅校正各大小层的候选数量权重，不消除长度、序列顺序或查询组成混杂。

| group 读数 | C0 | CL | CD | CLD |
| --- | ---: | ---: | ---: | ---: |
| 自然权重空集合质量 | 0.4950 | 0.4071 | 0.2284 | 0.2112 |
| 自然权重期望集合大小 | 0.5127 | 0.6358 | 0.8778 | 0.9323 |
| equal-k 期望集合大小 | 0.4713 | 0.5845 | 0.8591 | 0.9149 |

Sexism 的 L/D/LD 总体正方向虽然跨四种 score 一致，却不在每个固定大小层都成立。答案总分下，k=1/2/3/4 内 D 的平均变化依次为 **-1.581、+2.544、+4.110、-4.616**，L 为 -1.268、+0.877、+1.738、+0.656。这些是注册辅助描述点估计，没有 CI；k=0/5 的桶内 margin 为 NA。故本轮不能宣布“固定集合大小后仍普遍向 Sexism 移动”，更不能把跨 k 聚合直接解释成纯类别语义迁移。

固定 k 内 natural 与 count-corrected margin 只相差同一常数，配对变化中该常数消去。两者配对结果相同不是又一项独立的稳健性证据。

## 5. gold 辅助结果与边界

答案总分下，hate 的平均 gold 受限质量从 C0 的 0.4610 增至 CD 的 0.7171，CLD 为 0.6907；平均 gold NLL 分别为 2.8708、0.7789、0.8123。group 的对应受限质量为 0.5851、0.6303、0.6307，NLL 为 5.2524、4.7453、4.9928。不同辅助指标并不要求同向，尤其不能把 CLD 的微小质量增加说成全面优于 CD。这些不是自由生成准确率，未将 gold 辅助收益作为通过条件，也未新增其 CI。

gold 大小 0/1/>=2 的 query 数为 252/328/63，大小 2/3 附表为 56/7；完整分层和 rank/ties、gold-toggle、entropy、大小证据均在导出表中。gold 大小与 hate、词典命中及文本特征混杂，7 条的大小 3 层不能支持稳定机制结论。

全部 192 个端点在六个主分层使用 10,000 次 seed 42 联合 query bootstrap。区间是逐项、描述性的，未作同时覆盖或多重比较校正。dev 已参与开发，模型和数据历史暴露、标注质量、固定标签拼写与序列化顺序、受限候选空间的限制继续保留；bootstrap 和数值门禁都不能消除这些问题。

## 6. 结论与后续边界

本次数值测量的工程阻断已解除，且已得到完整 dev 的科学结果。当前最明确的后续研究对象是 **hate 对 D 的强正向响应，以及 L 在有/无 D 时不同的增量**。group 应以“主总分结果及其长度/集合大小敏感性”共同报告，而不是先假定已获得稳定的五桶语义偏移。

内部因果干预、14B/27B 扩展、微调、test 和利用方式均未在本轮自动开启。后续应先据本轮结果明确可证伪的机制假设与对照，再注册和执行相应阶段；不能由本轮非加性直接宣称内部机制已经识别。
