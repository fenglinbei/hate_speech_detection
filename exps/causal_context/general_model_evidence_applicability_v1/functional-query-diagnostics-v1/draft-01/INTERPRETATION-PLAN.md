# 功能诊断的预先判读标准（草案）

正文、适用性、hate参考和本文件均需在新查询模型运行前形成新冻结版本。当前是预先写出的AI方案，不是用户已采纳的机制假说。八条文本及其失败、反向、未决结果都保留；修改形成新版本，不能看分数后悄悄换题。

## 主要问题与估计范围

检验呈现lex-0419的行为作用，是否随查询中的普通笑声／人群称呼，以及作者认可／不认可攻击而变化。只对固定Qwen3-8B、任务提示、其他词典和示例背景成立。不是完整、无混杂的词义×立场因子实验：笑声组的攻击靠新增个人辱骂，称呼组通过反对／赞同改变立场；语法、对象、攻击种类和长度并不全部相同。

所有词条效应先在**同一查询内**计算，再比较其跨查询模式。A套称呼明示黑人，B套依靠称呼结构及待审词义确定所指；两套分别报告。八条是有目的的人工合成材料，分成两个相关措辞组，不以条件数、重复轮次、编码或探针数充当独立样本量，不报告自然分布准确率或总体显著性。

## 固定读出

各口径统一语义方向m＝score(non-hate)−score(hate)。原标签无EOS总分继续是主读出，原标签均分、NCC、A/B正映射和反映射并列展示；EOS辅助口径及全部单探针、留一结果保留。不同口径的原始数值不互相比大小，不挑一种作为新的主口径。

对查询q、示例措辞f、词条条件L：

- δ(q,f,L)＝m(q,f,L,嘿嘿示例)−m(q,f,L,哈哈示例)。负值表示嘿嘿示例相对更推向hate；不是查询词形替换的效果。
- 词条O→T：sH＝m(T,H)−m(O,H)，sA＝m(T,A)−m(O,A)。
- I＝sH−sA＝δ(T)−δ(O)：词条干预对示例词语差异的影响。
- C＝(sH+sA)/2：两种示例共有的判断移动。

第一阶段分别登记O→N1、O→N2为主比较，O→D为自然删除桥接，全部保留sH、sA、I、C和各条件预测。第二阶段登记P1→X1、P2→X2；O→P/X另列桥接。比值只在原差值数值可分辨时给出，反向与绝对值缩小分开写，未决不叫消失。

审核标签可用后令r(q)＝+1（non-hate）或−1（hate），GM＝r×m，ΔGM＝r×s，另报r×C。它们用于说明与参考的一致性，**不能代替原方向的C、I**。统一向non-hate平移自然会令non-hate题改善、hate题恶化，这种标签翻转本身不足以证明语境选择性。

## 跨查询的预定比较

每套查询措辞、每套示例、每种词条条件都保留两类区分度：

- K_L＝两种示例平均m(L0)−平均m(L1)：普通笑声中，无攻击与独立个人攻击的区分。
- K_G＝两种示例平均m(G0)−平均m(G1)：同一人群称呼内容中，反对与赞同的区分。

O→N1/N2及O→D分别报告ΔK_L、ΔK_G。正值说明该干预增大上述分数区分，不能脱离四个原始m判为整体准确率改善。

按同一拟定任务标签配对，另报J0＝C(G0)−C(L0)、J1＝C(G1)−C(L1)，以及T0＝I(G0)−I(L0)、T1＝I(G1)−I(L1)。所有方向事先均允许，未规定“G必须为正、L必须为负”。这些比较用于检验效应是否仅为查询间近似相同的平移，以及示例词语交互是否随查询变化；它们也含词序、对象和攻击形式差异，不能独自证明纯词义机制。

主适用性分层使用人审字段。若人审不认同某行的拟定cell或标签，该行仍保留，原设计比较保留为描述但标明该语义对比不成立；不悄悄换入另一条以凑2×2。标签未决仅排除该行的参考依赖结论；适用性未决仅排除该行的适用性分层结论。原始分数和不依赖标签的对照仍可报告。

**NCC的共享背景抵消。** 同一f/L/示例词形下，所有查询共享背景先验b，因此m_NCC(q)＝m_原均分(q)−b。固定背景的两查询差值中b抵消；K、ΔK、J和T的NCC版本在精确算术下应与原标签均分相等。将此设为代数核对，不能将两列相同称为两次独立证据。单查询m、δ、I、C的NCC版本仍有独立的背景校准项。

## 结果分类与后续行动

|---|---|---|
| N1/N2产生可分辨、跨示例措辞和查询层次一致的查询依赖；同时能区分G0/G1及L0/L1；A/B映射不推翻关键方向 | 支持这些受控查询中的语境依赖行为；单列仍误判的条件 | 选择有明确方向的同查询等长对照，冻结有限的机制试验 |

## 数值界及机制衔接

拟沿用epsilon＝0.0013427734375和现有FP32评分实现，但旧epsilon不是新运行自动验收。需完成历史重放、重复、成员顺序、设备副本、padding、prefix及派生评分检查，全部通过并封存原始分数后才用人审参考做分析。新实现或硬件变化须登记桥接，不事后放宽门槛。

原始m的界为epsilon；NCC m按原规则为2epsilon。线性比较先按相同提示合并系数，再按系数绝对值和传播；共享背景能代数抵消的比较按简化后的原始均分表达式核对。数值界不是统计置信区间，数值未决不等于零；本草案不设任意事后百分比或“显著性”阈值。

若进入内部试验，首轮最多4组同查询等长对照，先冻结donor/recipient、位置和方向。采集hook与self-patch须证明无扰动；分别在嘿嘿／哈哈示例条件实施双向干预，同时检查I恢复与C变化，并设无关位置/状态对照。答案前的同一提示状态干预用于全部候选，不能用已经喂入正确答案的donor。当前机制准备状态维持false。

功能诊断通过不自动开放原reserve。位置选择、读出、方向及失败处理规则冻结后，才安排其他审定案例及预留材料复制。
