## 配对背景与位置

P0 是改写配对示例、保留原顺序；P1 在相同背景中交换目标与配对示例。P0−R 衡量配对改写引入的总变化，P1−P0 才是本轮固定几何下的两示例顺序变化。

| 案例 | 配对背景 P0−R，主口径 | 顺序交换 P1−P0，主口径 |
| --- | --- | --- |
| 541 | 五个版本均下降，范围 −1.0008 至 −0.9303；原来正确的 A/C/D 全部变成 hate | A/D1/D2 下降；C1/C2 上升。共同背景中的十个 P0/P1 条件仍全为 hate |
| 3169 | A/D1/D2 小幅上升；C1/C2 分别下降 0.5106、0.7748，主口径变为 hate | 五个版本均上升，范围 +0.3703 至 +0.8212；P1-C1/C2 变为正确 non-hate，A/D 仍为 hate |

541 的位置作用随内容版本改变方向，两套位置×语义交互均为负。3169 的五项顺序效果在四种口径下均为正，但两套位置×语义交互分别为负、正，不能收束为一致的交互方向。

配对背景很有影响，尤其 541 不能把从原始输入到 P1 的总下降直接叫作位置效应。3169 的 P0-C2 在两个长度归一化口径下仍为正确 non-hate；541 的 P0-A 在 answer_mean 下也仍为 non-hate。这些口径差异均保留。

每次交换同时移动两条示例。541 交换第 5/9 位，3169 交换第 3/2 位；不能据此分离目标示例的绝对位置效应，也不能把两例当作同一交换距离的重复。
