# 3169：词条依赖与普通笑声适用边界

本实验响应用户本轮明确请求。先检验删除 lex-0419 后“嘿嘿－哈哈”差值是否改变，再检验明确排除普通笑声的说明是否改变该差值。使用已有查询 3169、两套已冻结的个人辱骂加普通笑声示例；不新增查询，不修改原始词条、人审记录、示例答案或其他九个示例，不重新检索词典。

新材料由助手编写并核对。用户授权实验操作和“普通笑声不适用”的边界，不等于逐字段人工采纳这些确切措辞。原定义的合理性判断与本次实验性限定分开保存。

## 预先确定的读数

所有分数按同一语义方向 m = score(non-hate) − score(hate) 计算，分别保留原标签总分／均分、NCC、A/B 正反映射；含 EOS 的原始辅助口径与背景、单探针、留一诊断全部导出。不同口径的数值大小不直接比较。

对每套示例措辞和每个词典条件 L：

- 配对差值 δ(L) = m(L, 嘿嘿) − m(L, 哈哈)。负值表示“嘿嘿”条件相对更推向 hate。
- 对两个词典条件 A→B，分别计算 sH = m(B, 嘿嘿) − m(A, 嘿嘿)，sO = m(B, 哈哈) − m(A, 哈哈)。
- 差值变化 I = δ(B) − δ(A) = sH − sO，是判断该说明是否参与配对差异的重点。
- 共同位移 C = (sH + sO) / 2，与 I 分开报告。

每套示例均注册以下 A→B 比较：O→D、O→N1/N2、D→E1/E2、N1/N2→E1/E2、O→P1/P2、O→X1/X2、P1/P2→X1/X2。每项均保留 sH、sO、I、C，不只挑选改变分类或方向有利的格子。

“减弱”同时报告绝对差值的减少量、剩余比例以及是否反向。只有原差值超出数值界才报告比例。落入数值界只称数值未决，不声称语义效应为零；I 未超界也不等于证明实质等效。不另设事后百分比或统计显著性阈值。

沿用 epsilon=0.0013427734375，单条件原始 margin 界为 epsilon、NCC 为 2 epsilon；任意线性比较按系数绝对值和传播。两项差值分别为 2／4 epsilon，四项差中差为 4／8 epsilon，共同位移为 2／4 epsilon。这些是数值界，不是抽样置信区间。

## 可支持和不能支持的解释

若自然删除和两套原位替换均使配对差值减弱，并且填充位置对照不推翻这一模式，可支持“呈现的这条说明参与或放大当前配对效应”。单纯删除结果包含长度和位置变化，不能独自承担该结论。

若删除／替换后仍保留接近原来的差值，可支持效应不完全依赖该词条说明；本实验不把模型已有知识与其他示例的贡献分开。两条件同向位移而 I 未分辨变化时，报告整体读数改变及配对差异变化不足以分辨。

若 X 相对匹配的 P 稳定改变 δ，而不只造成共同位移，支持显式适用边界影响了本次局部词语效应。它仍不是对模型“误用某个内部义项”的直接证明：新增排除措辞也可能提供具体词汇提示。新功能性查询和内部干预仍是后续独立步骤。
