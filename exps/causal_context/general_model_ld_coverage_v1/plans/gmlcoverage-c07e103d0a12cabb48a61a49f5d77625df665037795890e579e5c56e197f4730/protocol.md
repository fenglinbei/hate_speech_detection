本轮模型为同一冻结 Qwen3-8B 通用模型，不微调；其他模型及利用方式仍属后续任务。主总体为原完整 dev 643 条，每条等权，不改抽样框。分类是本次数值主任务：hate 两候选及 group 32 个集合；不运行提取任务。dev 已被前序实验暴露，不能称为首次未见数据。

保留 833 条冻结基础词典及全部冻结义项，不修定义、不加新词、不人工按上下文择义。词典 SHA256 为 `31240193eeba29f712560e2e80e89ee9dd5c3c969aa180d10b95bf2451882385`。匹配及资格、最长非重叠、义项保留规则沿用旧包。允许使用原 fit 示例文本和任务答案；不读取 test，不改 fit 检索池，不重检索 D。查询 gold 不进入输入构建、候选选择、预检、GPU 计分或 gate 判定。仅完整 raw 封存且验证之后，CPU 分析才连接原冻结 query gold。标注质量问题不在本轮修复。

## 3. 新 L 的定义

对每条查询 q，先固定原包为其选出的同一组 10 条 D 及顺序，然后构造：

- Lq(q)：原查询文本按冻结规则命中的词条。
- Ld(q)：这 10 条示例文本分别按同一规则命中的已有词条的并集，不用示例答案选定义。
- Lnew(q) = Lq(q) union Ld(q)。

词典只在一个全局块展示，按冻结 lexicon_id 的字符串升序排列。按冻结条目 ID 在全 prompt 的词典资料中去重，保留全部冻结 senses 及相应定义、类别；相同条目无论源自查询还是示例均使用同一渲染。查询文本、示例文本和答案本身不删重复词。内部条目 ID、来源、对应表、query ID、条件标记不进入模型输入；不新增逐示例块或推理解释。

原配/错配对照已取消，因为不显示对应关系时仅调换来源对应不会改变模型输入。本轮检验合并词典后的类别偏好变化，不检验显式绑定或“示例教会使用词典”。

## 4. 八条件

| 条件 | 词典块 | 示例块 | 地位 |
| --- | --- | --- | --- |
| C0 | 无 | 无 | 核心 |
| CLnew | Lnew | 无 | 核心 |
| CD | 无 | D | 核心 |
| CLDnew | Lnew | D | 核心 |
| PLnew | Lnew 的中性结构/近似长度对照 | 无 | 核心 |
| PD | 无 | D 的中性对照 | 核心 |
| CLq | Lq，使用本版固定 ID 顺序 | 无 | 辅助参考 |
| CLqD | Lq，使用本版固定 ID 顺序 | D | 辅助参考 |

D 的检索及 Lnew 在条件开关前固定。CLnew 关闭的是示例显示，并不去掉从示例得到的词典信息；不得因此退回 Lq、重检索或重新分配预算。LxD 是这两个固定显示块在读数尺度上的交互，不表示两个信息源相互独立。

两个 Lq 参考条件同批重建、重计分。旧 numeric-04 的查询跨度顺序不同，其分数只作历史参考，不拼入任何新配对差值。中性对照沿用原材料、结构匹配算法及绝对 8 tokens/相对 2% 的容差。词典为空时不插入空占位块。

## 5. 候选、计分与差值

使用原候选目录和 token 身份：hate 的 hate/non-hate 两规范 JSON 字符串；group 使用 Racism、Region、LGBTQ、Sexism、others 的固定顺序、bitmask 0-31 紧凑 JSON 集合。不增加排列或改序列化。

主分数为答案段 token logprob 总和，不计 EOS；保存逐 token、EOS 贡献、答案均分、含 EOS 总分及均分。hate 主 margin 为 s(hate)-s(non-hate)；group 对五类各取包含该类的 16 个集合与不包含该类的 16 个集合的 logsumexp 差。保留全部原有集合大小敏感性、包含概率、gold mass/NLL/rank/tie/best-nongold 等辅助读数。

四个核心差值：CLnew-C0、CD-C0、CLDnew-C0、CLDnew-CLnew-CD+C0。

原四个辅助差值：CLDnew-CD、CLDnew-CLnew、CLnew-PLnew、CD-PD。

仅增加两个参考差值：CLnew-CLq、CLDnew-CLqD。两者也报告描述性 CI；不添加两者之差作为新 estimand 或 CI。

## 6. 总体与区间

主读数为逐 query 配对 margin 差值的均值；保留中位数、分位数及数值可分辨方向计数。4 个分数口径 x 6 个 margin x 10 个差值，共 240 个 CI 目标（不是上下限端点数）。其中答案总分核心 24 个、答案总分辅助 36 个、其他口径敏感性 180 个。

保留六个原 CI 分层：all 643、Lq_hit 223、Lq_no_hit 420、gold group 大小 0/1/>=2。原 generic hit 明确指 Lq，不按新 L 覆盖重新分层。每层 240 个区间，共 1,440 个逐点描述性 95% CI；不解释为同时区间或验证性显著性。层内 query bootstrap 10,000 次，seed 42；同一层所有任务、差值和读数共用抽样。gold 辅助指标和新增覆盖/重叠/词条数盘点不增 CI。保留大小 2、3 附表，空层 NA 与真实零严格区分。

## 7. 容量与预检名单

原样保留 regression 8 条、validation 24 条。CPU 生成全部八条件后，对空 Lnew、最大 Lnew 词条数、最长完整词典块、最长完整候选输入四个边界各取一个代表，数值并列按 query ID 字符串升序。先确定代表，再与原 32 条及彼此去重；不为凑满 4 条选替代项。额外名单单列为 boundary cohort，最多 4 条。它们只扩大工程验收，不改变 643 条科学总体。实际名单及选择依据随运行包封存。

候选答案段、EOS、chat template 和提示边界对全部 174,896 个候选组合做 CPU 检查；同时确认 +64 masked padding 仍在 8,192 tokens 内。不得 top-k、截断或默默删词以通过预算。正式容量以本版八条件（含 PLnew）产物为准，之前的临时盘点不是封存回执。

## 8. 数值执行与停止规则

保留原已验证的计算实现：四张 L20 独立相同 FP32 副本，真实 forward batch 1，eager attention，禁 TF32，动态右 padding，无 KV cache，全序列 teacher forcing，仅答案/EOS 预测位置投影全部词表；seed 42、CPU threads 4。副本并行不等于 forward batch 4。新上下文长度表形成新的 runtime 身份，这是新输入的来源记录，不要求与旧运行的整个 runtime SHA 相同；模型、参数、tokenizer、源代码和实际计算策略保持冻结并重新核验。

沿用 E8=0.00067138671875、epsilon=0.0013427734375，不重新校准。每个非空 cohort 均从头执行六遍：batch1 baseline 带同 logits CPU FP64 参考、batch1 repeat、额外 64 padding、完整无缓存前缀参考、候选执行顺序变化、物理 GPU 循环迁移一位。repeat 和 CPU 算术参考各 <=1e-4；其余四类所有逐 token、EOS、候选分数和条件级 margin <=epsilon。几何、候选、有限性、身份和覆盖要求 100%。前缀只作独立参考，不作生产加速。

batch4 等价、size2 尾批及批内位置对真实 batch1 不适用，记录 NA，不称其通过。任一预检失败立即封存停止，不运行完整 dev、不自动换 profile、不以效果方向或准确率豁免。所有 cohort 通过且独立重算预检证据后，才自动扩展完整 643 x 2 x 8 = 10,288 blocks、643 x 8 x 34 = 174,896 candidates。

## 9. 封存与解释

新命名空间为 `general_model_ld_coverage_v1`。构建协议、config、输入、资源 trace、候选、名单和新/继承源码 SHA 身份。所有原版本及失败产物不改。断点仅复用同一新 plan、runtime、真实 batch1、prompt 身份的完整原子 block；失败封存不自动重试。完整 raw 顶层与每 shard 哈希、候选、顺序、几何及身份核验后才接 gold。GPU 副本在 CPU 分析前关闭。

结果同时交付原始分数、预检证据、独立核验、主/辅助结果和 EOS/集合大小附表。参考差值包含新增词条内容、类别、长度等总体输入变化，不分离纯语义作用。正向 margin 不等于准确率提升或平均概率上升；输入尺度非加性不等于内部机制已识别。固定排序、受限候选空间、答案长度、已暴露 dev、标注质量和单模型边界必须保留。
