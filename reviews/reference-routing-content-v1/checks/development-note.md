- capture-01：10项小型随机 CPU Qwen3 测试通过。

- runtime-01 / synthetic-01：实际调度器完成930个A阶段代数前向、464个单查询开发、256/360个单查询确认分支；故障、未授权、过期、缺少校准和重复写入拒绝测试通过。所有数值均为显式 synthetic。

- pipeline-02：修正上述测试路径后，4项端到端检查通过；控制器硬件和进程启动均使用明确 mock，没有研究 GPU 进程。
