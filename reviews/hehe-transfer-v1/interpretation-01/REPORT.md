# 新案例结果解读：规律开始扩展，强度仍取决于具体文本

本轮在两条新的普通笑声文本中，都复现了“原侮辱义导致误判、普通义恢复正确答案”；预先固定的第17层焦点替换，以及第26层注意力、第28层MLP的条件作用，也在四条新材料中得到支持。与此同时，是否翻转标签、效应有多大并不固定，尚不能把这些层解释成唯一的自然词义处理路径。

## 四条文本分别说明了什么

D01把“嘿嘿”解释为对黑人群体的侮辱性称呼；D02解释为普通笑声。只有这一个词条的释义改变，任务、其余五词和查询原文不变，不提供示例。

| 查询与来源 | 完整原文 | 参考 | D01输出 | D02输出 | 两种释义的分数差 |
|---|---|---|---|---|---:|
| T01，COLD 2640 | 山东人莫名自豪一把，嘿嘿 | 无 | 有 | 无 | +29.361 |
| T02，COLD 3562 | 看到有人拿老实举例，我还是挺高兴的，因为我也想用老实举例来着，嘿嘿。 | 无 | 有 | 无 | +37.249 |
| T03，主语料 #7050 | 你去帮你的嘿嘿打工吧 | 有，按用户要求沿用原标签 | 有 | 有 | +7.600 |
| T04，COLD 9078 | 我并没有瞧不起少数民族，就是瞧不起某个把中国拖入痛苦深渊的种族，旗装，嘿嘿，最适合满人大姑娘抽烟袋的时候穿 | 有 | 有 | 有 | +1.077 |

分数使用 **m = z(无) − z(有)**，衡量模型更偏向哪个答案；表末列为 D02 的 m 减去 D01 的 m。因此正值表示换成普通义后更偏“无”，对 T01/T02 有利，对 T03/T04 不利。这是输出分数差，不是概率或准确率。

**T01/T02使旧现象不再只依赖原来的普通笑声案例。** 两条原文都没有对人的攻击，却在原释义下答“有”，换普通义后答“无”。这支持词典释义会在某些普通语境中把判断带偏。

**T03提供了一个需要保留的不同结果。** 普通义使“有”的优势减小，但 m 从 −22.938 变为 −15.337，仍然偏“有”，没有重现旧 Q02 换普通义后误判的标签翻转。它的参考采用已经确定；这里不额外把原数据标签写成新的族群指代或严重度裁决。

**T04说明普通义没有在这条文本中抹去全文的其他攻击。** “瞧不起某个……种族”等独立攻击证据仍然存在，两种释义都输出“有”，分数只相差约1.08。它是边界证据，不能当作第二条人群指代用法的复现，也不能由一条文本推出模型总能结合全文判断。

## 第17层的因果干预也能迁移，但翻转模式有变化

激活替换是把某种释义条件下、查询“嘿嘿”位置的完整内部向量放进另一种条件的运行，再观察答案怎样改变。这里固定第17层，层号从0开始，没有为新案例重新挑层。

| 查询 | 普通义向量放入原释义运行：Δm / 输出 | 原释义向量放入普通义运行：Δm / 输出 |
|---|---:|---:|
| T01 | +11.647 / 仍为有 | −25.620 / 无→有，造成误判 |
| T02 | +33.079 / 有→无，修复误判 | −17.661 / 仍为无 |
| T03 | +3.910 / 仍为有 | −6.155 / 仍为有 |
| T04 | +0.828 / 仍为有 | −0.566 / 仍为有 |

8个方向中，焦点替换都朝供体条件的答案倾向移动，且效应绝对值都大于各自前置位置对照。前置对照最大的绝对变化为0.275，全部没有翻转标签。但对照是等数量的邻近token，并非词性或向量大小匹配：T01/T02/T04使用逗号，T03使用“你的”，不能因此把位置差异完全归因于纯词义信息。

T01的正向替换虽改变分数，却不足以修复；反向替换足以把正确答案改错。T02则相反。**因此，较稳定的是固定位置能够传递释义条件的影响，标签是否翻转还受原生分数距离零点有多远、干预幅度等因素影响。** 不应只保留成功翻转的方向。

另一个有用线索是：四条文本在第17层的焦点向量差大小（L2范数）都约19–25，但最终分数效应相差很大。尤其T04并非内部向量完全没变；变化传到答案时的幅度较小。不过，向量大小相近不表示承载的内容或方向相同，当前还不能据此定位一个专门“抑制词典”的语境模块。

## 后续层位有一致性，也有抵消和未解释的剩余

答案方向投影是用最终输出头和RMS归一化读取中间状态，观察它偏向“有”还是“无”，不表示该层已经作出决定。

在 T01/T02 的原生条件比较中，第23层MLP、第26层注意力、第28层MLP再次明显扩大两种释义的差距。T03在第26层却出现注意力新增约+2.15、MLP新增约−1.99的相互抵消；T04整体变化较小。后续29、32、35层也有扩大、回落和RMS重缩放，不能概括成单调放大。

![原生条件差距与每层新增差距](../results-01/condition-gaps.png)

图中比较D02−D01，读取答案前位置，层号0起，保留全部36层。**各面板纵轴独立缩放，不能用线条高度直接比较T01与T04的绝对效应。** 注意力、MLP的投影增量及其分支/RMS分解是诊断读数，不是可相加的独立因果贡献。

在第17层焦点替换之后，将答案前第26层注意力输出、或第28层MLP输出恢复为当前条件的原生向量，24个“案例×方向×恢复配置”的剩余效应绝对值都减小。联合恢复在8个方向中都比任一单独恢复减弱得更多，移除原替换效应的 **18.8%–46.8%**，仍剩 **53.2%–81.2%**。

这些恢复使用整个子层输出向量；“注意力输出”指o_proj后的向量，与注意力热图权重不同。比例衡量固定上游干预被削弱多少，不是正确率、修复率或独立中介贡献。所有方向中，联合移除量都小于两个单独移除量之和；这说明当前分数尺度下并非简单相加，不能单独据此确认冗余或唯一串行路径。

![固定层干预的最终效应](../results-01/endpoint-effects.png)

柱高为干预后m减去原生接收方m，面板标题的方向按供体→接收方理解。零线表示回到接收方原生分数，不统一表示正确；面板纵轴同样独立缩放。

## 目前可以采用的阶段性表述

在这批经过内容审核的新案例中，词典释义能够通过查询“嘿嘿”位置的内部状态影响最终判断；固定的第17层替换及下游第26层注意力、第28层MLP恢复效应可以迁移。普通语境中重现了释义诱发误判，另有攻击证据的文本则可能保留正确标签。影响方向有一致性，幅度与标签翻转仍依具体文本而变化。

这里支持的是同一冻结方案在四条新文本上的延伸。没有重新搜索最佳层或头，8个方向不是8个独立样本，也不由这四条材料估计总体成功率。全文语境怎样改变向量方向及后续处理、联合恢复后的剩余经哪些位置传递，仍未被本轮隔离。
