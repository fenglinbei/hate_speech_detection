# 材料准备过程记录

本轮为 AI 候选材料准备，未读取本批模型输出、加载模型权重或运行 GPU。人工采纳数始终为0。

长度匹配仅使用本地 Qwen3 tokenizer。初稿保存在 authoring-01.py；wording-selection-01 至05分别保留0、12、66、96、108条已完成同组同标签长度匹配的示例，未匹配项也保留。新增可选措辞只依据自然表达、语义和token数，不能当成目标模型试验。最终人工可见文本采用05；中间选项不进入正式候选。

AI复核发现并排除了“存放置在”“认真仔细”“毫无任何”“为了看不起”等由机械改词产生的不自然组合，修正原始“整个人人格”的笔误。原稿和完整替换记录均留存。没有用无意义填充补长，没有降低冻结协议的等长或未替换token一致门槛。

build-01完成材料构建及独立CPU复核。交付版draft-01的数据JSON和提示预览与其字节相同，另增加审核说明和最终离线工作台。桌面首次查看通过；手机截图显示队列被高度约束压缩，随后修正CSS并新增队列可见高度断言，browser-02通过。其后截图发现继承的手机侧栏固定高度造成留白，明确重置高度并补充断言，最终browser-03通过。

浏览器准备中发现系统Node12不满足Playwright要求，改用已有/tmp/node-v22.19.0-linux-x64/bin/node；默认浏览器缓存为空，改用已有/tmp/paired-review-playwright下的Chromium。沙盒禁止Chromium进程通信，按工具正式升级流程获准在主机上做同一本地离线检查；没有绕过拒绝或访问线上会话。Chromium使用临时上下文并禁用GPU，所有测试裁决均为synthetic，未写入候选包中的人工字段或真实审核库。

checks/browser-01、browser-02和browser-03的回执／截图只证明页面行为，不是用户材料裁决。后续审核应以draft-01的原文字节及独立导出记录为准。
