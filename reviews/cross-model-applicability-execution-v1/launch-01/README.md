**此文件记录启动方案，实时进展以每个运行目录的 state.json 和 gpu.log 为准。** 不得因为旧 CPU 选择器仍写着未启动而重复创建任务。每模型先执行五个工程 pass，再完成 16 条预选格式探针；全部通过、进程正常退出并经 CPU check 后，才可用同一绑定进入 full。full 复用已封存工程请求，新增模型先评分旧 156 条，再评分新 384 条。失败为终止状态，不能自动重启或放宽标准。

三模型总预算为 8100 次工程前向和 1464 次科学前向，另有至多 336 次格式续写前向。不是独立案例数。旧 8B 的 156 个工程重放不替换其历史科学分数。

需要暂停本实验时，在对应运行目录创建 STOP；它会在当前请求提交后暂停。不要停止其他进程。只有 paused 可用原绑定显式续跑；qualified 可通过 full 进入科学阶段；failed 和 complete 均不得重启。

最终分析必须等待各自原始科学评分封存和真实工作进程退出。自然语境主开发组（花瓶／小丑）与词义解释型补充组（寄生虫／木头）分别报告，保留全部查询、反例、未决和分类损害。跨模型比较方向和分类结果，不直接比较原始 margin 大小，不声称独立确认。
