# 逐模型工程资格

全部判据在目标模型新输出前固定。三个模型分别验收；同一数值上限是本轮明确选择的FP32工程标准，不是继承旧8B实测误差或共享某个模型的资格。

| 检查 | 规则 |
|---|---|
| 完整性 | 每模型540输入，五个工程pass；候选来自同一有限FP32完整词表向量 |
| 重复／请求顺序 | 与reference的margin最大绝对差为0 |
| 左／右补齐 | 分别与reference相比，margin最大绝对差不超过0.001 |
| 同logits计算恒等式 | m与logP(无)−logP(有)之差不超过1e-10 |
| 每模型工程界 | max(1e-6, 2×本模型实际最大工程margin差) |
| 格式 | 每条新查询预选最长条件，共16条；均须输出单个候选token后接EOS，不以答案正确性筛选 |
| 科学评分复核 | 每个production margin与其reference相差不超过该模型工程界 |

每条查询的格式条件在CPU上按token数最大、再按condition_id确定；不看输出挑探针。第一步复用reference完整词表向量，后续最多7次前向。合法答案质量完整保存，没有根据事后低质量阈值删掉条件。

误差界只表示该模型、当前权重／实现／设备布局下的工程重复性；不是统计置信区间、实用等效范围或科学显著性。主科学阈值和确认规模尚未冻结。模型内部的线性表达式先按physical_score_id合并共享项，再传播界；跨模型不直接混合margin大小。

资格失败使运行进入failed并停止，不自动重试或换模型。任一已提交请求可在同绑定、同运行时的显式paused续跑中复用，记录及原始向量须逐项重建一致。完整记录、资格回执、producer identity、运行调用和资源释放证据一起保留。

旧8B的156个输入在工程阶段重放，供之后与历史读取作诊断。它们不替换历史科学记录，也未借用历史误差界；如果设备／运行时不同，应报告差异，不能以这次重放重新书写历史结果。

分析入口要求production seal、全部数值／格式回执和正常工作进程退出证明。随后才解析查询参考，分别输出新材料与旧材料报告。自然语境主开发和词义解释型补充分别汇总；不根据某模型结果决定是否删除另一个模型或某类查询。
