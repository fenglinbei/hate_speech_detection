# 三模型 CPU 执行准备完成

这版绑定已经采纳的科学输入：两自然语境开发家族（花瓶／小丑）＋两词义解释型补充家族（寄生虫／木头），共16查询、384新条件。两类分别报告，不能称为四个同质主实验家族。另保留旧12查询的120核心＋36N复验；旧8B科学结果保持原身份，不被工程重放覆盖。

科学冻结见[冻结说明](../../../docs/research/experiment-plans/cross-model-applicability-v1/frozen-01/README.md)。两次人工决定均为对AI材料及关系的整批采纳；48项原材料和240条关系已采纳，新查询没有原始Gold。原稿、旧人工字段、旧实验选择器均保留。

本版实现三模型的本地载入、FP32前向、最后有效位置取分、FP64计算、工程验收、格式诊断、完整评分、已提交请求续用、原始向量与来源保存、资源释放后的分析。科学运行时先完成两新增模型的旧条件评分，再完成各自新材料评分；旧条件报告保留全部12查询和N，不只选择历史J2。

**当前没有设备绑定、GPU运行、队列或轮询。** 已通过的9项测试使用微型随机CPU模型及合成评分流程，没有加载研究模型的预训练权重。执行准备封存不等于GPU资格。当前会话的一次只读nvidia-smi查询无法访问驱动，不能据此判断宿主机GPU是否空闲；后续运行窗口须重新实查。

## 已核查

- 1620份token输入逐条对应科学冻结：每模型384新＋156旧。查询参考、人工标签及关系不进入评分输入。
- Qwen和本地GLM微型CPU模型：直接读最后有效隐藏状态再投影，与原生完整forward的对应位置一致到CPU测试误差；左右补齐位置正确；微型safetensors重载逐值一致。
- 模拟完整工程／格式／科学流程：暂停后复用3条已提交请求，原记录字节保持不变；篡改答案位置被拒绝。该资源释放记录是明确标识的测试夹具，不是实际GPU释放证明。
- 60位Decimal独立检查评分，最大差约1.78e-15；物理评分别名先合并再传播工程界。保留未决、修复和损害，分别汇总自然语境组与解释型补充组。
- 新材料1152个比较、旧材料168个核心比较和36个外部N条件均接入。没有确认性统计结论。

## 工作量和运行边界

| 模型 | 工程输入／前向 | 新科学前向 | 格式额外前向上限 |
|---|---:|---:|---:|
| Qwen3-8B | 540／2700 | 384 | 112 |
| Qwen3-14B | 540／2700 | 540 | 112 |
| GLM-4-9B-Chat | 540／2700 | 540 | 112 |
| 合计 | 1620／8100 | 1464 | 336 |

五个工程pass覆盖每个实际输入：原始、重复、左补齐、右补齐、反向请求顺序。8B的156个旧输入只作工程重放，新科学前向没有重复计入它们。总计9564次prompt-only前向，格式生成最多另加336次；不是9564个独立实验案例。每模型单独形成数值资格，不能复制旧8B或其他模型的实测误差界。

支持一张卡或按层划分的两张卡；具体UUID和布局只在新的GPU窗口绑定。单／双卡布局的真实显存及吞吐尚未测量。不同模型可以使用不重叠的设备；同模型改变设备或布局必须重新取得资格。本版不支持CPU／磁盘卸载、量化、KV复用或batch>1。

默认run只做engineering，合格后退出并释放工作进程。只有显式选择full才继续科学评分；已有qualified运行可以进入full，复用已封存工程记录。只有显式paused允许续跑；failed和complete禁止重启。STOP文件在完成当前请求后停下。不能停止其他用户进程。
