## 任务与输入

使用 Qwen3-8B、36 层、32 个 query heads，原生 FP32 eager forward，batch 1、无 KV cache、无量化或 CPU/offload。任务指令为当前冻结版本，输出为单 token“有／无”。每例保留 10 条完整真实示例，词典分别为 2 / 6 个原始词条；示例展示答案按用户确认的已审核标签映射，原历史标签及来源仍保留。[完整材料与审核来源](/data/liaozijie/hate_speech_detection/reviews/case-attention-v1/prepared-01/MATERIALS.md)。

条件为 C0 无资料，D 仅示例，L 词典释义，LD 词典释义＋示例，LC 词典释义及原始类别，LDC 词典释义及类别＋示例。两例的已审核查询参考均映射为“无”。这套最新任务框架与历史 prompt 不同，历史预测不作为本次重放目标。

主读数为生成答案前最后有效位置 `pre_answer`。辅助读数包括词典结束 `lexicon_end`、完整示例结束且查询尚未提供 `demos_end`、查询末尾 `query_end`、查询全部 token 的平均 `query_all` 和查询焦点词 `query_focal`。已采集全部层与头，正文/答案、词形/释义/类别和跨片段边界 token 均保留单独视图。主分数 (m=z_{无}-z_{有})：正值偏向“无”，负值偏向“有”。
