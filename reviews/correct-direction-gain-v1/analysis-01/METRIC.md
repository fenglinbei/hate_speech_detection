# 正确方向推进量 G：报告约定 v1

用户于 2026-09-21 确认采用该报告项，并要求复算最新方案。它具体化已有评分协议中的 reference_aligned_change，不替代冻结的主 margin，也不修改历史结果。当前复算属于已暴露材料上的事后描述分析。

同一查询、同一人工参考下，m = z无 − z有；参考为无时 y = +1，参考为有时 y = −1。定义 G = y × (m方法 − m基准)。基准必须按比较组明确固定。G 大于零表示向正确答案推进，小于零表示退步；G 的单位是两候选 log odds 的变化，不是准确率百分点，也不是实际正确概率。

固定报告以下内容：

- 逐查询基准 margin、方法 margin、G、传播后的工程误差界、方向，以及原生／方法分类与转移。
- 参考无、参考有各自的平均 G，以及两类等权的平衡 G。先按词项组等权、组内查询等权计算每类均值；本次词典三组均各有两无两有，因此与直接类别均值相同。
- 全体查询均值、中位数、极值，以及推进／退步／精确零／数值未决的数量与比例。精确零要求 G 及传播界都为零；其余方向只有在绝对值超过传播界时才可分辨。
- 修复、新增损害、保持正确、仍错误与数值未决转移；修复率以原生明确错误数为分母，损害率以原生明确正确数为分母。

同一查询的多个次序分别报告，不把次序当新样本；不同比较基准不合并。词项组只是汇总权重，不代表独立来源；本次没有置信区间或独立泛化主张。参考标签仅进入事后评价，不进入 U、+7 或 CAD 的执行规则。

工程误差按实际评分 ID 合并系数后传播。U − N 的界为 bU + bN；去参考 − N 为 b0 + bN。+7 − N 中 N 完全相消，G = 7y，传播界为零；CAD(α=0.5) − N = 0.5(N − M00)，界为 0.5(bN + b0)。数值可分辨不等于统计显著或实际重要。

一个正的平衡 G 不能单独证明方法更好：原本已正确的案例进一步增加 margin 也会贡献正 G，少数大幅变化可能支配均值。固定 +7 的平衡 G 恒为零，也不否定它能够纠正决策边界。结合逐类结果、分布及修复／损害解释；不按该新指标重新挑选当前已经暴露的案例、层、强度或 CAD 参数。
