# 攻击严重度：试行标注规则 v1

## 测量对象

`attack_severity` 评估可见文本中作者认可的、针对人的贬损及伤害主张的严重程度。它是与 hate/group 并行的有序字段，取整数 0–4 或 null。机构、制度、资本等抽象对象沿用本任务既有对象范围，不能仅凭比喻将其改写为具体人群。

本字段不测标注者本人的冒犯感、作者情绪激烈程度、预测置信度或已经发生的现实伤害。分值只有顺序含义，4 不代表 2 的两倍严重。

## 分级锚点

| 等级 | 锚点 | 边界 |
| --- | --- | --- |
| 0 无攻击 | 中性讨论、普通赞同、单纯反驳攻击，没有另外认可的贬损或伤害主张 | 提及身份或引用被反驳的攻击词不升级。 |
| 1 轻度贬损 | 轻蔑、挖苦、轻度负面概括 | 已有贬损义，但没有下列较强内容；并非所有玩笑都属于 1。 |
| 2 明确侮辱 | 直接人格羞辱、侮辱性归类或明显的群体污名概括 | 区别于普通质疑和行为批评；粗俗词、缩写或重复次数不能单独决定等级。 |
| 3 严重贬斥或排斥 | 认定对象天生低等、不配作为人，或主张因身份剥夺平等参与和基本权利 | 判断命题是否否定人的地位或权利；泛用“垃圾”骂词不自动等于非人化。 |
| 4 暴力认可或主张 | 合理化、赞许针对人的身体伤害，或直接威胁、鼓动此类伤害 | 仅叙述、引用反驳或中性讨论暴力不升级。 |
| null 待定 | 证据不足以可靠选择等级 | 写明缺失信息或待讨论边界；不以 0 代替未知，也不取中间分折中。 |

## 形式与证据

为保留同等级内的差别，另记录可多选的 `attack_forms`：

| 值 | 含义 |
| --- | --- |
| `derogation` | 一般贬损 |
| `personal_insult` | 人格侮辱 |
| `group_stigmatization` | 群体污名 |
| `dehumanization` | 非人化 |
| `exclusion_or_rights_denial` | 排斥／剥夺权利；理由须说明是何种排斥 |
| `violence_endorsement` | 暴力正当化或赞许 |
| `violence_threat_or_call` | 暴力威胁／号召 |

形式是描述，不能按字段名机械推导分数。例如一般排斥态度是否已涉及平等参与权利，需要结合实际命题判断。记录短引文、对象、作者立场与一句理由；未确定是否获作者认可的高强度形式仅放在候选说明中。

## 判定与来源规则

1. 先识别对象、命题和作者立场，再评级；反仇恨表述中的独立辱骂仍需计入。使用与 hate/group 相同的可见证据范围。
2. 一句有多项获认可的攻击时，整句分取有证据支持的最高等级，并在说明中保留对应对象和形式；不能将最高分传播给所有提到的人群。
3. hate 与严重度独立判断。轻度 hate 可仍为 hate；不将所有 non-hate 自动赋为 0，不以严重度阈值重算 hate。旧 hate/group 记录保留其原政策身份。
4. 使用 `scored` 表示已形成 AI 数值草稿，`needs_discussion` 表示边界或解释待讨论，`insufficient_evidence` 表示关键信息不足。后两者的 `attack_severity` 均为 null；候选分与倾向分是讨论材料，不是活动分值。
5. 没有严重度记录表示尚未标注；已经看过但无法定级的 null 必须附原因。接受规则不把 AI 草稿转成人工评分，不把整批疑点已处理转成人工整项确认。
6. 每条记录绑定正文哈希、对象版本、严重度规则身份与所参照的标签记录。辅助材料和旧 group 若使用不同政策，保留各自版本，不能冒充已按统一口径重审。
7. 初次试标沿用每批集中讨论的节奏。若相邻等级长期难以区分，记录并显式修订规则，保留旧版及旧分值。
