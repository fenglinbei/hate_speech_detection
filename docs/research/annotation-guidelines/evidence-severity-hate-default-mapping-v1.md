本增补适用于 `v2-reannotation-20260911` 的本地当前结果及后续批次。从已有严重度记录开始应用，并保留原记录。尚未赋分的条目不根据旧 hate 反推严重度。

| 活动严重度 | 当前默认 hate |
| --- | --- |
| 0 | non-hate |
| 1、2、3、4 | hate |
| null 或尚未赋分 | null，不能计算映射 |

只有活动分值参与映射。讨论中的候选分、倾向分不能替代待定值。先确定可见文本的对象、作者立场及攻击严重度，再生成 hate；不因映射要求改动分数。group 仍按其有效规则单独标注。

本增补替代[严重度规则 v1](evidence-attack-severity-policy-v1.md)“判定与来源规则”第 3 条中独立生成 hate 的约定；分级、证据及对象范围不变。原文件、原 v2 政策、已接受提案和既有裁决均保留，不能修改历史内容来消除规则变化。

当前映射结果单独导出，并绑定严重度来源和本规则身份。原标签及其政策保留在参照层，差异明确显示。AI 分数生成的 hate 仍依赖 AI 判断；用户分数生成的 hate 标为“用户分数＋规则映射”，不额外算一次用户直接 hate 裁决。#4392 另有明确的 hate 个案回复，独立保存。

若已有人工 hate 与当前映射不同，保留旧裁决并显示差异，当前结果按新默认映射生成。严重度 null 不覆盖历史 hate，只表示新映射暂无结果。暂行映射没有隐含例外；后续明确更正或例外需另存来源和版本。

本次规则确认没有新增线上材料确认，也没有部署或修改权威人审会话。规则及 AI 协助裁决不作为独立标注一致性或量表有效性的证明。
