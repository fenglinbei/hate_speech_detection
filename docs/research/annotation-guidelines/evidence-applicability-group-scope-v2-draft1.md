本稿回答“异性恋是否归 others”“其余类别如何归入 others”及“什么时候选无类别”。这是拟议的语义修订分支，不是对旧数据完整标注范围的事实断言。

## 1. 可执行定义

group 标注文本中实际作为评价、辩护或攻击对象的**人群身份或社会角色**。因某种身份评价一个人，也属于该身份对象；人数并非门槛。先确定对象及其身份在命题中的作用，再映射类别。

现有五类由四个专门类别 `Racism / Region / LGBTQ / Sexism` 和剩余类别 `others` 组成：

> 当文本明确以某种人群身份或社会角色为评价、辩护或攻击单位，且已确定本命题实际评价的身份或角色维度不能映射到四个专门类别时，group 归入 `others`。

明确提及某种身份不足以成立 group；身份只是背景，或仅描述某人的具体行为时，不因身份词出现赋类。对群体的正面评价、非仇恨辩护也适用本定义。作者明确辩护的类比群体可以是实际对象，不能仅因承担类比功能就排除。

## 2. 本次具体化的范围

| 对象或表达 | 拟议规则 |
| --- | --- |
| 按“异性恋”这一性取向身份评价或辩护人群 | `others`；异性恋这一属性本身不映射为 LGBTQ，也不映射为 Sexism |
| 职业、宗教信仰、年龄、社会阶层、组织成员、兴趣社群等身份或角色 | 明确作为对象，且能排除四个专门类别时，归 `others` |
| 游客、乘客、观众等角色 | 不要求群体长期稳定；只有以角色为评价单位时才归类 |
| 多重身份 | 只映射实际参与评价的身份；同一人可以有异性恋与跨性别等多重属性，按跨性别身份评价时应考虑 LGBTQ，不能用异性恋属性抹去其他实际身份对象 |
| 只有个人目标，未以群体身份或角色评价 | group 为 `[]`；个人辱骂是否 hate 仍按父规则独立裁决 |
| 只有机构、企业、平台、政府本身，未指向成员身份 | group 为 `[]`；机构冒犯是否 hate 仍按父规则独立裁决 |
| 机构名可能转喻成员、经营者或居民，且不同读法改变 group | 保留 `null`，记录需区分的对象及语境；不能机械套用机构 `[]` |
| 只因共同在场或某次行为指认的几个人 | 人数多不自动构成身份对象；若只评价具体行为，无其他身份对象，则为 `[]` |
| 身份、地名等仅为背景；对象为地点、物品、事件或抽象观点 | 无其他实际人群身份对象时为 `[]` |
| 抽象讨论 d12“性取向”“群体偏见”等概念 | 不自动枚举所有可能的性取向或群体类别；结合文本实际具体对象判断 |
| 对象属于 Racism 还是 Region 等专门类别仍无法确定 | 保留 `null`；`others` 不用于容纳类别选择的不确定性 |

本稿不规定所有国籍、民族或交叠身份的唯一映射。剩余类别的判定要求能排除四个专门类别，不能把尚未解决的专门类别边界整体移入 others。

## 3. 三种结果与决定顺序

1. 确认文本中是否存在作为评价、辩护或攻击单位的人群身份／社会角色。指代可以隐含，但必须有文本内可核对的依据；不能补造上文或用召回示例代替上文。
2. 若判断充分，确实没有这种对象，选 `[]`。有身份词但仅作背景也可为 `[]`。
3. 对每个实际身份对象，能映射专门类别则取该类别；已排除四个专门类别则取 `others`。
4. 对多个实际对象取类别并集。多个群体映到同一个类别时去重。
5. 若文本内证据支持的合理读法中，某个实际对象或类别尚未确定，且会改变完整类别集合，正式 group 仍为 `null`，保留已知部分及候选理由。不能用部分集合、`others` 或 `[]` 替代未决，也不能仅凭没有文本依据的猜测制造未决。

`others` 表示已确认的其他身份／角色类别，`[]` 表示已确认无实际群体身份对象，`null` 表示仍有影响答案的不确定性。三者不随 hate 标签自动变化。

## 4. 演示与本轮讨论的文本

以下短句为自拟规则演示，只展示 group，不能从表格反推 hate：

| 文本 | group | 依据 |
| --- | --- | --- |
| 我的异性恋同事今天迟到了。 | `[]` | 陈述个人行为，身份是背景 |
| 异性恋不该因一个人的行为被全体污名化。 | `["others"]` | 明确辩护异性恋群体 |
| 同性恋者也应该得到平等对待。 | `["LGBTQ"]` | 明确辩护同性恋群体 |
| 他是护士，所以不值得尊重。 | `["others"]` | 针对个人的职业身份评价 |
| 这家公司的收费不透明。 | `[]` | 评价机构的具体行为 |
| 这家公司的员工天生低人一等。 | `["others"]` | 明确针对成员群体 |
| 刚才插队的三个人应该离队。 | `[]` | 对具体行为提出处置要求 |
| 游客这种人都不值得尊重。 | `["others"]` | 按角色贬损人群 |

对本任务用户提供的“我也没因为……是异性恋就讨厌所有异性恋……性取向和道德水平又不相关”一段，按本草案建议：

- hate：`non-hate`。作者明确反对由个体行为泛化到整个群体，没有另行发起身份攻击。
- group：`["others"]`。文本直接辩护异性恋群体，即使这一命题具有类比作用，也有独立的群体评价对象。
- 不凭这一段补入隐含的同性恋对象，也不因泛指“性取向”而枚举 LGBTQ 等全部可能类别。

该建议依据用户提供的文字，不将句中关于现实人物的身份设定视为经核实的个人事实；没有读取该案例的 Gold、预测或为本稿检索其他案例正文。
