# CPU完成边界与后续执行顺序

模型已经采纳为Qwen3-8B、Qwen3-14B与本地GLM-4-9B-Chat快照。模型模板／tokenizer适配沿用原核查实现；Qwen以enable_thinking=False渲染，GLM使用其本地原生模板。CPU发现的候选ID分别为Qwen有18830／无42192、GLM有98318／无98479，必须以每模型实际CPU记录绑定，不跨模型复制ID或数值容差。

23个权重文件的全哈希复用首批已封存清单，本次只复核元数据哈希与权重大小／mtime，未声称重新读完全部权重。正式运行时仍需验证权重及实现身份。GLM本地tokenizer／实现与查到的上游版本差异已记录，不能为通过资格静默升级或换成转换模型。

FP32仅权重估算约8B 32.76GB、14B 59.07GB、GLM 37.60GB（十进制GB）；这不包含运行缓冲、激活或注意力工作空间。14B不能按“有四卡”直接推断单卡可装；实际GPU型号、显存和布局须在后续窗口绑定。不得为省显存静默换精度或量化。GPU吞吐尚未测量，不提供伪精确壁钟时间。

新增科学工作量为384×3＝1152次新材料前向，加156×2＝312次旧材料新模型复验，共1464次prompt-only前向；每次同时读取有／无logits。工程资格、格式自由生成及必要8B桥接另计。1620份CPU模板重建包含旧8B，不意味着重启旧GPU运行。

后续资格和科学阶段须使用另版代码及清单；资格失败保留证据并停止，不能根据科学效应更换模型或放宽界限。评分期间只读模型输入，封存原始评分、验收并释放资源后才加入人工参考分析。CPU结构通过不等于模型数值通过。
