# 分析和暴露：四词项扩充版

继承[已交付的研究目标与预期分支](../draft-01/RESEARCH-SPEC.md)及[矩阵定义](../draft-01/CONDITIONS.md)，以下说明本版增补。首批文本及192个输入保持完全相同；24项原材料与120条关系的人工整批采纳另存。新两族均为开发侧AI草稿。所有新增查询的原始Gold和original_correct为空，人工参考不是原始数据集Gold。

每查询仍为15核心＋3N＋6标签对应诊断。m=z无−z有；E为同一D背景下L相对L0的增量，I为E相对无D的变化。固定W比较R，固定R比较W；只交换标签的比较保持相同文本、顺序和标签总数。analysis-plan.json逐ID登记1152个表达式，其中416个是优先探索读数，不是416个独立假设或预注册显著性检验。科学阈值、等效范围、多重比较处理和确认停止规则仍未指定。

在每个模型内报告原方向、参考对齐方向、工程未决、实际分类修复／损害。核查不适用L的基线是否确实有害，再描述D是否缓解；基线没有有害效应时仍保留该查询，不按失败与否筛选。分类变正确与L的负增量消失分别报告。非零I只反对严格L无关的加性D偏移；不能排除一般的答案倾向。适用L可能因D提供冗余词义而增量变小，不据此宣称使用失败。

跨模型保留方向不一致、没有基线错误、局部有效和反向效果。三模型均覆盖相同开发矩阵，不以某模型先出现正结果为另一个运行的条件，不把原始margin大小混合排序。Qwen两规模和一个GLM快照不能分别识别纯规模因果或纯架构因果。

## 两种构造分别报告

- A：花瓶／小丑，固定独立辱骂前景＋无攻击锚点，正常顺序有／无。
- B：寄生虫／木头，中性词语解释前景＋攻击锚点，正常顺序无／有。

两组都在同一查询内维持四格的数量、标签组成、位置和各前景的规则关系；新增组的词语解释规则对所有目标均建议none。B组直接提供解释性语义，可能使L增量冗余，也可能激活不同的任务做法。A/B同时改变词项、示例文体、标签与锚点属性、标签次序；它们只构成不同构造下的覆盖检查，不能估计单独的构造或标签顺序效应。

模型内可给词项等权的描述汇总，但同时保存16条查询、4词项和两构造分层的全部结果。四词项继续保守放在CMAD-DEV-C01共享依赖簇，不能以384输入、3模型或工程重复计算独立样本量。所有查询仍是普通义对应无、贬称义对应有，没有凭两个新词解开查询层面的用法—参考对应。当前范围不足以建立普遍的纯适用性因果结论。
