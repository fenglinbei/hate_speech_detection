# 基线、正确方向推进与双侧评价

## 方法和参数预算

固定 `m=z无−z有`；有=18830，无=42192。参考无时 y=+1，参考有时 y=−1。精确平局、工程未决及非有限值按父评分协议处理，不强分为正确。

| ID | 固定方法 | 额外代价／开发预算 |
|---|---|---|
| N | 原生参考提示 | 1次参考 forward |
| NOREF | 同查询 M00 的 m0 | 1次无参考 forward；可复用 |
| U | 无参考供体，第17层目标词 block 输出、强度1、所有合格查询均应用 | 供体与接收运行；不看 gold、margin 或是否需要修复 |
| OFFSET7 | mN+7 | CPU；沿用旧常量，不在本批重拟合 |
| CAD05 | 1.5mN−0.5m0 | 两候选 margin 的 CAD 对照；α固定0.5，不称完整生成实现 |
| QAS | 在 N 背景，第18–35层 p 行全部 heads，对 query_all key 的 softmax 前 score 加 ln(f) | 单次运行；开发只比较 f∈{1,2,4}，不找层／头／语义跨度 |
| N_CAL | mN+bN | 一个开发拟合偏移 |
| U_CAL | mU+bU | 同样一个开发拟合偏移；预注册任务推进候选 |

QAS 保留 mask、V 和其他 attention 行；f=1 必须复现 N。这是本项目直接增加查询注意力的基线，**不冒称既有论文算法的完整复现**。既要保留 OFFSET7/CAD05，也给原生模型和 U 相同的一个标量校准预算，防止把边界移动当成内部方法独有收益。

所有方法评价14条件中的13个有参考条件；NOREF 复用同查询 M00，不能把复制分数当新 forward。U 不作用于 M00；M00是原生供体。A 阶段 P 不计入 B 的强方法竞赛。

只使用24条开发查询的 MPS/MSP 拟合。主聚合为同查询两次序平均，再在词项内按类别等权、词项等权；本批平衡构成时相当于48个开发端点等权，独立查询仍只有24。

- b 候选：0；排序后的唯一 margin 相邻值的负中点；`−max(m)−1`、`−min(m)+1`。分别为 N/U 建候选集合，最大化上述 balanced accuracy；平局取 |b|最小，再取数值更小的 b。工程误差带内的预测计入未决且不算正确。保存整个候选表和选择理由。
- QAS 最大化相同开发 balanced accuracy；平局取 f 最小。f=1不另作模型运行。
- 在开发上选定比较基线 B*：N、NOREF、OFFSET7、CAD05、QAS、N_CAL 中 balanced accuracy 最高者；平局依次按相对N损害数更少，再按上述固定 ID 顺序。U及U_CAL不参加选 B*。

开发结束后另封存 bN、bU、f、B* 及来源，确认阶段只应用一次。不得根据确认结果更换基线冠军、选 raw/calibrated 中较好者或增加参数搜索；仍完整公开所有方案。任何人工查看确认输出都登记为暴露；调参后的结果另列为探索。

## G 与分类结果并列

对每一查询／条件以该条件 N 为固定基准：`G=y(m方法−mN)`。单位为两候选 log odds 的变化，不是概率或准确率百分点。报告：

1. 每条原生／方法 margin、G、误差界、方向、原生／方法预测；两次序不隐藏。
2. 无类与有类各自平均 G、两类平衡 G；先词项内平均再词项等权。同基准的全体均值、中位数、极值与推进／退步／精确零／未决数量一起保留。
3. balanced accuracy、普通 accuracy、逐类正确率、AUROC（无为正类，分数m）；精确同分 AUC 计0.5。按每个次序先算AUC再平均，不以margin平均后的AUC冒充同一量。工程近同分额外报告上下界。
4. 修复、损害、保持正确、仍错、未决五类转移；修复率分母为原生明确错误数，损害率分母为原生明确正确数。主次序均值之外保留逐查询任一次序受损的并集数。
5. 分别列出四情形、熟悉／新词项、每个词项；不把提示、参考槽位、层和头当独立样本。成本报告同设备墙钟、峰值显存、forward和处理token数，区分首次供体捕获与缓存复用。

每类平均等权时 OFFSET7 的平衡 G 恒为0；任何共同常量校准也不改变平衡 G。这是代数性质，不代表没有分类收益。因此不以 G 排名替代 accuracy、AUROC 或成本。很大的已正确 margin 也可能主导 G，必须保留中位数与损害分布。

主表按不同基准分组，M00→参考的输入效应另表。工程界先合并同一评分 ID 的线性系数再传播，例如 G_OFFSET7=7y 的差值界为0；CAD05−N=0.5(N−M00)；不把重复使用N算成两个独立误差源。

## 参考贡献的双侧评价

对预注册的每个单槽位比较，C 是完整混合参考，C[k←Bk] 只替换一个示例：

`E_method(q,k)=y[m_method(C)−m_method(C[k←Bk])]`。

`D_method=E_method−E_N` 衡量方法怎样改变这条参考相对背景替代物的作用。不能把去掉全部示例的差值归因于其中一条。B可能有作用，所以 E 是配对相对贡献，而非该示例的绝对使用量。

人审的 direct/none 分组在结果前固定，并列报告所有 E；不因结果变好把 none 改成 direct。另以原生 E_N 的结果做**事先规定的事后行为分层**，不用于筛选材料、执行方法或调整确认批次：

- 有益参考：`E_N−b(E_N)>δ`；有害参考：`E_N+b(E_N)<−δ`；其余为小效应或未决。δ固定0.5 log odds。
- 有益保留：`E_U−b(E_U)>0` 且 `D_U−b(D_U)≥−δ`。同时报告该提示的分类损害；保留相对贡献不能掩盖整体判错。
- 有害削弱：`D_U−b(D_U)>δ`。若仍负，称部分削弱；只有误差区间已不低于−δ才称进入小伤害带。反向增强有害作用单列。

报告每侧的合格分母、逐例值、同查询合格槽位平均、再按词项等权的均值。主观察量是原生U；U_CAL/常量偏移不会改变同查询E，不能重复计为两份机制证据。CAD05的 E 恒为1.5E_N、NOREF的 E 恒为0，作为实现核对；CAD仍可能在主任务上更好，两类结论分别写。

δ=0.5、有益容忍损失0.5以及后文的样本／晋级门槛，是本轮事先固定的实用判断和资源分配标准，不是公认阈值、功效分析或显著性界。小样本只做完整描述；不报将相关提示视为独立样本的 p 值或置信区间。
