# 第18层 A/V 分解

## 比较对象

固定 Qwen3-8B，36层、32个 query heads、8个 KV heads、head_dim=128。沿用已有 FP32 eager、eval、batch=1、use_cache=false；读数在 FP64 计算。具体权重和 tokenizer 沿用被绑定的 model-profile，实际运行前重新验证文件身份和数值资格。

对每个 J05–J10、每个 MPS/MSP：

- N：当前混合参考提示的原生运行。
- U：相同提示，在 zero-based17 block 输出，以同查询 M00 原生的目标词全部 token 状态作供体，强度1。只改目标词位置 T，不改答案前位置 p。
- P：沿用旧实验等 token 数的紧邻前置位置替换，作为位置诊断。它没有范数或词类匹配，不能当作必然无效的安慰剂。

供体／接收提示长度不同，必须各自按已有 token 位置映射；不能把 M00 的第18层 A/V 直接塞入参考提示。下述 A_N、V_N 与 A_U、V_U **都来自同一个参考提示的 N/U 运行**，形状、位置、mask 完全相同。

## 四格操作

在 U 运行背景，只替换第18层 p 位置的完整 attention 输出，位置在 o_proj 之后、加 residual 之前：

`O_ab(p) = W_O concat_h [ A_a(h,p,:) V_b(h,:,:) ]`，a,b∈{0,1}，0=N，1=U。

| 格子 | A | V | 含义 |
|---|---|---|---|
| 11 | U | U | U 自身重建；应复现 U |
| 01 | N | U | 将读取权重恢复为原生，保留 U 内容 |
| 10 | U | N | 保留 U 读取权重，将内容恢复为原生 |
| 00 | N | N | 两者共同恢复；其他位置仍在 U 背景 |

采用真实 Q/K norm、RoPE、GQA repeat_kv、因果 mask、softmax 精度和 o_proj；不得先平均 heads 再组合。运行中的其他 attention 行、residual 和后续计算照常保留。00 在第18层 p 输出处应回到 N，但后续层仍可读取其他 U 位置，因此其最终分数不要求等于 N。

注册配置为：18N、12U、12P、36个非平凡混合格（01/10/00）、12个11自身重建、12个N背景00重建、12个第17层原生自身替换，共 **114个评分配置**。12个 N 背景00属于实现对照，不是上述 U 背景00。实际 forward 数还包括工程重复、格式检查与必要捕获，须在后续执行包中明确预算；本清单不伪称已运行或已完成资格检查。

必须重放旧18N、12U、12P的完整最终词表向量、原有目标状态及轨迹；不能用旧分数替代本次 forward。复现失败则保留失败并停止科学解释，不修改旧结果、门槛或来源来通过。

## 对比和结构预测

所有 m 在同一答案前下一 token 位置计算。固定：

`E_A = m11 − m01`（在 U 内容下的读取贡献）；

`E_V = m11 − m10`（在 U 读取下的内容贡献）；

`E_joint = m11 − m00`；

`I_AV = m11 − m10 − m01 + m00`；

并保留另一背景的 `m10−m00`、`m01−m00`，满足 `E_joint = E_A + E_V − I_AV`。各格另外报告 `G_ab = y(m_ab−mN)`，以区分传播某种影响与推进正确判断。这里的贡献是有限干预对比，不是唯一自然通路、全局中介份额或错误修复率。禁止用接近零的 U−N 作归一化分母来排名机制。

由于第17层只改 T，模型局部结构预测在第18层入口：p 的 Q 不变，T 外的 K/V 不变。对每个 head、任意未改且未 mask 的 j,k，N/U 的 `log A(p,j)−log A(p,k)` 应相同。实现检查优先比较 softmax 前 score 差及共同归一化项，避免零概率的 log。**查询总注意力上升不能单独证明重新聚焦作者立场**：T 外所有 key 可以只是共同缩放。

该不变量只适用于第18层这个读出位置及这次局部替换；不得延伸到后续层或先跨头平均的比值。若失败，先检查实际改动范围、Q/K/V来源、mask、位置和精度，不把实现偏差命名为新机制。

## 捕获和误差

第18层保存 N/U 的实际 p 行 Q、归一化及 RoPE 后 K、V、softmax 前 score、A、逐 head AV、o_proj 后输出；校验只有预定行被覆盖。保存全部36层原有 pre-answer residual、attention、MLP 及 RMS 轨迹。观察所有 heads；本协议不按结果挑头实施额外干预。

注意力按互斥、穷尽 key 集合汇总：查询目标词、查询前文、查询后文、示例正文、示例标签、示例其余结构、其余提示。以被绑定输入的 token/span 标记生成；各类 token 数、总量和逐 token 均值一起报告。旧材料没有新增“正确立场 token”的人工标注，不凭解释临时圈定。新材料的语义跨度须在模型结果前审核，并作为独立标记展示，不能替代穷尽结构分区。

后续 runtime 必须做小型 CPU hook 测试（原生同一模块、GQA、mask、重建、只改p、供体身份），再做真实模型工程资格；本包 CPU 代数 fixture 不替代这些测试。工程精度沿用父约束上限（scaled state/reconstruction 1e−4、projection absolute 1e−3、floor 1e−6），不能因新实验失败放宽。每个评分记录的实际误差界从新资格实验得到。

误差按真实记录 ID 先合并系数，再取系数绝对值加权界。独立四格交互是四个记录的界之和；自身共用同一记录时必须消去。工程可分辨性与本协议的实际量级阈值 δ=0.5 log odds 分列；任何一项都不是统计显著性。
