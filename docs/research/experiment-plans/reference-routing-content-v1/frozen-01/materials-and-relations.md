# 材料与关系审核

## 冻结材料框架，不冒充已采纳材料

主批次48条新写查询：24开发、24确认。开发为已暴露词项京巴／垃圾／公交车 × 四种情形 × 两条不同构式；确认为这三词各四条新构式，加三个新词项各四条。新词项的三个槽位在本版尚无文本身份，必须在首次模型运行前，依据普通／贬损用法可构造性、人审可判性及历史材料登记选择并冻结；不得依模型错误率选词。若无法填满，公开缺口并另版修订，不能按模型结果补题。

| 情形 | 构造意图 | 预期审核方向（不是人工裁决） |
|---|---|---|
| ordinary_clean | 目标词为普通义，全文没有其他攻击 | 无 |
| ordinary_other_attack | 目标词为普通义，同时存在针对个人／群体的独立攻击 | 有 |
| quoted_opposition | 转述贬损表达，作者反对，且不另行攻击 | 无 |
| endorsed_attack | 作者实施或认可目标表达的攻击 | 有 |

四类都保留，避免“普通义→无、贬损义→有”的捷径。期望构成不覆盖人审；出现不同裁决时保留原稿、理由和修订链，在模型输出前决定修订或替换。每个词×情形槽位都留下失败记录，不能悄悄删除难例。目标词在查询中恰好出现一次，覆盖其全部 token；其他实体、引用和独立攻击位置必须可审查。

开发与确认的查询、示例文本、构式／近重复家族分开，不共享仅改姓名或词面的模板。登记 `term_family_id`、`construction_family_id`、来源及暴露。全部材料审核与两批划分在开发模型结果前冻结；确认不参与校准或条件选择。相同词项、同一作者构造与共有任务背景仍可能依赖，因此“24确认”不等于24个独立自然样本；新词子集12条单独报告。

旧 J05–J10 与本批均隔离；A 阶段旧文本和旧示例不能复制为 B 确认样本。既有 P/S 使用分组不升级为已审定的适用性关系。

## 三类审核分别进行

1. **材料**：原文自然、指代／引用／作者立场明确、无答案暗示；按父 human-rules 审核查询答案与示例答案，严重度可未决但二分类不得伪造。示例必须先有可追溯 accepted 答案。
2. **关系**：逐“具体示例→具体查询”使用父 relation-record schema；`semantic_reference_fit`（词义／所指信息）与 `rule_fit`（判断规则）分别审。`direct/partial/none/unclear/null` 保留原义；主语义对照只接纳明确 direct/none，rule_fit 保持其真实取值。
3. **实现约束**：原文字节、Unicode code point 半开跨度、目标词所有出现、token 映射、长度、示例次序和来源身份。偏移需对原文逐字匹配，不以规范化后文本代替。

审核说明引用具体 source/target spans，登记作者立场、引用范围、所指、独立攻击和决定相关性。词面重合独立记录，不当作适用证据。通用判断规则可能适用于两组；不能为做二分而把它改成 none。

AI 可以先写建议；所有新 `human_reference`、`accepted_fields`、`decision_ref` 起始为空。用户本次采纳的是研究设计，**不是未展示材料的人工裁决**。后续材料采纳必须绑定具体原文与字段；保留是否见过模型输出、旧金标签、AI建议和相关旧结果的暴露信息。审核时不展示本批目标模型结果。

若需要工作台，复用现有逐项审核实现并开独立 session；不改旧人工记录、不迁移线上会话。这里只冻结契约，不部署工作台。

## 固定四示例与单槽位对照

每条查询预先登记三组正确示例，各四条：A1–A4 的语义／所指关系为 direct；I1–I4 为 none；B1–B4 为不同词面背景示例，语义关系 none，规则关系照实审。各组答案位置恒为 `[无,有,无,有]`。B 不是被假定无效的资料，它是有明确身份的替代比较对象。

六个基本提示（词典均为空）：

| 条件 | 四个示例槽位 |
|---|---|
| M00 | 无示例，保留父模板的空占位 |
| BG | B1 B2 B3 B4 |
| BA | A1 A2 A3 A4 |
| BI | I1 I2 I3 I4 |
| MPS | A1 A2 I1 I2 |
| MSP | I1 I2 A1 A2 |

另对 MPS/MSP 各四个位置，分别将该位置换成同位置 Bk，得到八个单槽位对照。总共 **14个提示条件／查询**。主比较 MPS/MSP 是相同四条示例的顺序变化，答案位置保持不变；BG/BA/BI 是预注册辅助条件，不能与单槽位替换混称为同一种因果比较。

A/I 的两个答案方向都必须成立，不能“适用示例总给正确标签，不适用示例总给错误标签”。A 的有标签示例可以含独立攻击；其具体 rule_fit 仍须分别审核。每个源材料在查询处为何提供／不提供所操纵的词义信息，必须能够解释。

用最终 tokenizer 验证每个单槽位替换**完整序列 token 数相等，未替换文本对应的 token 身份和绝对位置相等**；A1/I1/B1/B3、A2/I2/B2/B4 相应匹配。BA/BI/BG 对应槽位亦匹配。保留自然表达，不能插入无意义填充或类别暗示凑长度。无法匹配的记录不得用于“只改变该示例信息”的主对比；在运行前修订材料或另版注册宽松对照，不能在看到分数后降低标准。

后续科学输入冻结必须包含：48条查询与来源／家族、全部示例及采纳、所有关系与原文跨度、14条件的原样提示和 token IDs、精确补丁映射、分组矩阵及排除台账。模型输入只含父任务、查询、参考正文与示例答案；查询 gold、关系标签、适用组标记和解释不会进入模型。
