# 结果分流标准

按下列顺序报告，但机制、任务、双侧三条结论分别保留。不能仅因 U 未胜过 +7 就抹去机制证据，也不能因 A/V 有效就宣布方法有任务优势。

## 0. 可解释性资格

文件／材料身份、查询标签采纳、位置映射、自身重建、旧端点重放或新数值资格失败：该阶段标记 `engineering_or_input_unqualified`，停止科学排名。保留失败、原始输出和未完成配置；修订写入新版本，不放宽旧门槛。不重启旧 COMPLETE 实验。

本协议不授权新 GPU 运行。A 阶段需新 hook 和执行冻结；B 阶段还需材料／关系采纳、精确输入及开发参数冻结。批准规则、构造候选、通过 CPU 合同测试，均不能替代这些事实状态。

## 1. A/V 机制分流

δ=0.5。对 EA/EV/I 的“明显”要求绝对值减传播界大于δ；“小”要求绝对值加界不超过δ；中间带为未决。正负以及 y 对齐后的方向都报告。

- **读取候选**：EA明显、EV小、I小，且EA与E_joint同号；同一查询两个次序都成立。
- **内容候选**：EV明显、EA小、I小，且EV与E_joint同号；同一查询两个次序都成立。
- **耦合或背景依赖**：两者都明显、I明显、或两次序互相冲突；保留完整四格，不能强分唯一通路。
- **该位置证据有限**：上述候选不足；包括只有微小效应或误差未决。不能推导模型没有读取／内容机制。

只有六条中至少四条满足同一种单路候选，才把该路列为下一轮优先细化对象；其余查询及反向结果必须同表保留。此门槛只决定资源优先级，不提供跨词泛化证据。结果不自动授权新层、头扫描或改变本版固定U。

## 2. 任务方法分流（B 确认24条）

U_CAL 是预注册推进候选，B*在开发时选定。若确认集上同时满足以下条件，标记 `candidate_for_larger_validation`：

1. 相对 B* 的主 balanced accuracy 提升至少1/24（约4.17个百分点，按查询内两次序平均）；
2. 对两个类别的正确率均不低于B*；相对N的新增损害数不高于B*，并且“任一次序受损”的查询并集数也不更高；
3. U_CAL相对N的平衡G在传播工程界后仍大于0；无类／有类的G分别公开；
4. 熟悉词／新词的分表与运行成本完整，所有数值和格式资格通过。

这是扩大验证的资源门槛，不能写成统计显著或已优于所有方法。若只提高G而未提高分类，记 `margin_gain_without_task_advantage`；只校准改善分类则如实记 `calibration_assisted_gain`。没有超过B*不继续自动扩样追分；先分析失败、损害和成本，再另立研究选择。所有固定基线即使在确认上超过B*也必须完整显示，不能隐藏；不得据此更换预注册的主比较对象。

## 3. 双侧作用分流

首先按预注册E_N分层计数。每一侧至少覆盖两条不同查询、两个词项，才足以讨论本批“既减害又保益”；不足时标记 `one_sided_or_insufficient`。有益／有害不由人审关系标签直接推定。

覆盖满足后，只有同时满足以下条件才标记 `limited_bilateral_evidence`：

- 有害侧按查询内槽位平均、词项等权的 D_U，其保守工程下界大于δ；超过半数合格查询的平均D_U下界大于0；
- 有益侧同权重D_U下界不低于−δ，至少80%的合格查询在两个次序所有合格槽位上满足“有益保留”；
- 有益侧的完整混合提示中，U没有把原生明确正确的判断变错或变成数值未决。

80%以查询为分母，需向上取整；不以槽位数量充当样本。所有未保留、增强伤害、不同次序冲突与新增整体损害均列出。若未达标，记 `mixed_or_negative_bilateral_result`，不删去坏例以挽救结论。即使达标也只支持本批配对替代条件下的有限证据，不能声明已建立普遍适用性理解。

## 合并后的下一步

| 机制 | 任务／双侧 | 后续方向 |
|---|---|---|
| 有稳定候选 | 任务与双侧均过门槛 | 扩大冻结后验证；另协议细化对应读取或内容模块 |
| 有稳定候选 | 任务未过，或只有单侧材料 | 保留机制线索，优先补齐关系与双侧条件；不包装成纠错优势 |
| 机制有限 | 任务有收益 | 将U_CAL作为经验候选复验，限制第18层机制解释 |
| 耦合／不稳定 | 方法无优势或新增损害 | 报告负结果，重新审视固定局部规则；停止无目标扩层／扩头 |

所有后续方向都是研究分流，不是新执行授权。没有触发任何好结果时也按同一模板收尾：完整矩阵、失败与未决、方法成本、结论边界，禁止只展示最佳查询或最佳次序。
