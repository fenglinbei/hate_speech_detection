# 任务规则、适用关系与主评分协议 v1

协议身份：`task-applicability-scoring/v1`。状态：**协议冻结完成**。本轮用户明确授权：“主评分规格可以冻结，适用关系字段规范也可以按照之前的建议冻结，。请帮我完成这一步的收尾”。授权来源为当前 Codex 任务中的用户消息；确认的是规则和规格，不是具体材料的人工裁决。

## 核心约定

1. 任务为“作者是否实施或认可针对个人或群体的攻击”，包含轻度贬损和个人攻击；不限制为受保护群体。引用、反驳、对象及独立攻击的处理见模型任务与人审规则。
2. 资料本身正确、关系适用、模型实际使用、任务表现改善分别记录。词典关系以具体义项及出现位置为单位；示例的词义／所指信息关系与判断规则关系分列。
3. 关系值为 `direct / partial / none / unclear`。未审值为 null；结构上不适用的维度整体为 null。主二元对照仅使用所操纵维度的 direct 与 none，保留其他维度，不能把 partial/unclear 归入 none。
4. 主评分固定为同一下一 token 位置的 `m = log P(无) - log P(有) = z无 - z有`。不计引号、EOS，不平均 token 长度，不扣 NCC。精确平局不任意分配类别；数值误差带另列。
5. 输入效应固定方向为 `Δm = m(处理条件) - m(对照条件)`，但“正”不等于“有益”。按参考方向另外计算一致性变化，分别保留修复、损伤及未决。

## 完成边界

本次完成的是**任务—关系—评分协议**，不是科学材料／执行矩阵冻结。CPU 回执验证文件来源、字段、位置、拼装、单 token 候选和答案边界；不证明材料标签正确、模型行为符合任务或 GPU 数值已合格。

下一阶段制作跨词项材料，按本 schema 审核并登记家族、暴露与比较关系；随后把具体材料、条件顺序、科学对比、确认划分和运行数值资格绑定到单独的输入／执行冻结。该阶段沿用本协议的候选、阈值和公式，不能按科学结果选择更有利的编码或适用标签。

执行配置中的设备、批大小、数值误差资格回执及具体诊断子集由该输入／执行冻结绑定。本协议已经固定误差带的使用和传播算法；尚无运行资格回执时，数值可分辨性必须记为未验证，不能借用历史 Q01 通过状态。

本轮没有创建新材料裁决，没有读取保留集，没有更改线上工作台，没有加载权重或运行 GPU；旧研究结果、政策身份和 `mechanism_ready=false` 保持其原有含义。
