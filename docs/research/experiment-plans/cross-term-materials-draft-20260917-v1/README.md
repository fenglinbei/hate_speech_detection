# 跨词项材料：第一批可审核草案

状态：**AI 起草，尚未人工采纳或冻结为实验输入**。本批共 3 个候选词项、12 条新写查询，先研究词典单独作用，示例 D 为空。采用 [任务—关系—评分协议 v1](../task-applicability-scoring-v1/frozen-01/README.md)。人审字段全部留空，表中的分数、答案和关系均是 AI 建议；没有新模型输出。

三个词项均来自既有审核材料，因此仅作开发与构造校准。三个词项共享“普通所指／贬人用法、反对称呼、另行辱骂”等构造；不是 12 个独立样本，也不宣称是 3 个独立确认家族。后续确认材料另选未参与开发的词项及构造家族。

## 这批检查什么

先检查能否在明确语境中把“指定义项适用”与“当前作者实施攻击”分别标注。每个词都提供四类查询：适用且攻击、不适用且无攻击、适用但反对攻击、不适用但有另一处独立攻击。后三者尤其用于检查审核口径是否能分开。

四格是本批构造草案，不是假定四格已经消除了其他差异。反对称呼改变了作者立场，另行辱骂增加了另一条攻击命题；它们作为分列的边界条件，不把跨句分数差直接当成纯义项适用性效应。主要输入效应先在同一查询的不同资料条件内计算。

## 每条查询的三种资料条件草案

| 条件 | 词典位置 | 用途与限制 |
|---|---|---|
| Ø | 不放条目；由冻结 renderer 显示“（无）” | 同查询基线。 |
| L | 对应的单列贬损义项 | 观察这条具体释义的输入效应。 |
| N | 下列字形说明 | 保留完整研究词形、移除贬损释义的候选对照；本版尚未完成长度匹配，也不把它当成绝对无作用的中性内容。 |

N 的实际候选文本如下：

- 垃圾：这个词按“垃”“圾”的顺序书写，包含两个汉字；词条中按这一顺序记录。
- 京巴：这个词按“京”“巴”的顺序书写，包含两个汉字；词条中按这一顺序记录。
- 公交车：这个词按“公”“交”“车”的顺序书写，包含三个汉字；词条中按这一顺序记录。

这给出 12×3＝36 个拟定条件，全部 D 为空。N 不标为 lexicon_sense，也不向它套用贬损义项的 sense_fit；它是单独的形式对照材料。长度、提示中的实际位置及完整输入在正式输入冻结前再检查。此次未生成正式 prompt 帧，未把 36 条件写成 GPU 执行计划。

后续可分别登记 `m(L)−m(Ø)`、`m(N)−m(Ø)` 和 `m(L)−m(N)`。L−N 仍是指定语义释义相对字形说明的效果，不能单独证明抽象语义因果；词面频率、长度、字形分解和提示格式的伴随差异要另审。

## 人工审核重点与当前限制

1. **三个新释义是否准确。** 尤其京巴是否同意按本次单列的地域辱称义审核；旧犬种义仍保留在历史来源中。
2. **12 句是否自然，标签建议是否成立。** G3/J3/B3 的义项适用与无攻击是否可以同时成立；G4/J4/B4 是否清楚呈现“研究词无攻击，但别处另有攻击”。
3. **强度与边界。** J1 是否需要不同等级；其他直接贬称是否确属明确侮辱。若有依据的解释分歧影响标签或关系，保留 partial/unclear/null，不为填满格子强行定案。
4. **研究覆盖。** 本批使用清楚的普通用法和明确的攻击／反对线索，适合校准构造与审核；可能过于容易，不能据此保证词典会带来信息增量，也不能由小效应断定模型不使用词典。
5. **共享模板。** 三条独立辱骂都用了“蠢货”，三条反对句使用相近结构；这便于核对，但限制独立性和自然度。后续扩展须登记并增加构造差异，不能把换词算成新增独立样本。

本版先交付 L 的最小材料草案。D 单独作用与 L+D 组合按上一轮顺序后续构造；本稿没有给示例关系补造评级。旧保留集没有读取，旧实验与人工记录没有改动。
