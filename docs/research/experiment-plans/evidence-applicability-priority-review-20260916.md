# 证据适用性研究：优先级调整评审

日期：2026-09-16。作者：assistant。性质：基于用户指定对话**最后一轮设计批评**形成的研究建议，不是已获人工采纳的新科学协议、输入冻结或 GPU 执行计划。前一轮仓库总结仅用于事实核对。

对话来源：[整理研究目标进展](chatgpt-conversation://6aaa60c9-719c-83eb-a025-13d13d7b2f2e)。本次完整读取了可用的两轮对话，并核对相关本地协议、最新解释及模块全视图、例外和标签表。文献依据另从原始论文页面核查。没有重新执行模型或开展完整数值重审。

后续核查补充：人工材料口径还包含 2026-09-11 已采纳的“严重度 0→non-hate、1–4→hate”增补；旧模型提示没有同步明写这一范围。因此不能笼统把个人攻击都说成尚未定义。下一步首先整合已确认规则及其适用范围，见[任务、适用关系与主评分讨论稿](task-applicability-scoring-discussion-20260916.md)。

**建议立即调整的优先级：先建立跨语义家族、能够区分竞争解释的受控行为现象，再决定内部实验要解释什么。** Q01 的进一步细化和向已暴露查询的迁移退出下一阶段主任务，保留为已有探索结果和后续候选。研究首先聚焦“材料本身正确，但其中某项信息不适用于当前语境”的证据使用；不同时承担一般证据可信度判断、资源路由和分类性能优化。

**为什么需要改变顺序。** 现有工作已经证明了若干输入和内部替换的因果效应，但这些效应的功能含义尚不足以决定下一轮定位范围。C/I 分解的是指定输入对比下的共同移动与交互；恢复 C/I 不直接测量义项选择、证据适用性判断或作者立场理解。以恢复最大作为选择标准，会容许综合下游状态成为赢家。工程误差界通过、同一查询的多种条件一致以及跨独立材料的功能重复，分别回答不同问题。

|---|---|---|
| [643 条 dev 六条件](../../../exps/causal_context/general_model_ld_nolabel_v1/RESULTS.md)：hate Macro-F1 的 CD 为 71.32%，CLDnew 为 62.36%，CLDnewNoCat 为 66.84% | 固定系统中资源组合有实质性行为差异；去掉类别字段未消除全部点值差距 | 保留现象背景；不能说整个项目只有单案例证据，也不能把差距直接归因于适用性失败 |

**对最后一轮批评的取舍。** 应采纳其三个主判断：研究对象要重新操作化；跨家族的辨别性证据优先于单案例深挖；评分与验证的组合规模要由科学问题约束。以下修正同样必要，避免把这轮建议变成另一套过大的实验。

- “先行为、后机制”不要求先证明模型正确使用证据。稳定的误用、标签跟随或混合策略同样可以成为内部机制研究对象。
- 适用、带来信息增量、改变模型输出、提高分类表现是四个不同判断。不能用“加上后变对”定义适用性，也不能由“没有改善”认定模型没有使用证据。材料审核只能描述判题需要的信息，不能直接断言模型内部不知道什么。
- 词面、语义与标签路径可以共同起作用。标签数量相同只能排除简单的标签比例解释，不能排除模型按词面选择某个示例并复制其标签。
- “语义适用性 × 词面重合”的表格只是构造目标，不自动保证因果因素已经正交。作者立场、目标、攻击强度、长度和标签对应的伴随变化仍须审核。
- 已冻结的局部试验在它自身范围内仍然有效；新的研究方向也不能把过去的注册改称无效。应改变今后计算的优先级和论文主张范围。

**收窄后的主问题。** 在固定 Qwen3-8B 和明确的 hate 判断规则下，经过审核的词义与示例信息对判断的影响，是否随其语境适用关系变化？词面重合、示例标签对应和一般输出偏好，各能解释哪些变化？先完成 hate 主线；group 相关事实仍用于核查对象与义项，不同步展开完整 group 分类机制矩阵。

首个功能切片优先选择**同一词形的不同义项／用法**，跨多个词项建立配对。它直接承接现有发现，又能检验效应是否超出“嘿嘿”。立场、引用和群体泛化作为后续预定边界，不能一开始全部交叉。新材料中 hate 与 non-hate 均须覆盖，避免把“适用”编码成某一个答案。

**第一步：统一任务与适用关系。** 为新实验写出简短、模型可见的任务规范，确保提示、示例答案、材料审核和评测使用同一版本。整合[基础审核规则](../annotation-guidelines/evidence-applicability-annotation-policy-v2.md)与后来已采纳的[严重度映射](../annotation-guidelines/evidence-severity-hate-default-mapping-v1.md)：已成立的轻度贬损及个人辱骂可以计入 hate，不能擅自收窄为群体攻击。旧模型提示未明确这一范围；确实仍有争议的目标或立场暂不承担主结论。新提示属于新的实验条件，不能把成绩直接当作旧系统的同口径提升。

每份材料明确记录三种关系：词典义项是否适用于查询中的具体出现位置；是否适用于示例中的具体出现位置；示例中的哪项词义或判断规则能够迁移到查询。定义本身的正确性和示例答案正确性另列。某示例在词义上无关，仍可能提供格式或一般判断规则，故不使用笼统的“整体毫无用处”标签。

先研究信息本身正确的适用性边界。错误定义或错误标签属于单独的可靠性干预；若错误在模型可见信息中无法识别，不能把接受它直接归为可靠性判断失败。[DefVerify](https://aclanthology.org/2025.coling-main.293/)提供了定义、模型行为及工作流偏差分开检查的方法依据，但不是本项目已经存在某种内部缺陷的证明。

**第二步：一个小规模行为先导，分开操纵 L 和 D。** 初始以 12–20 个新语义家族作为预算起点，用于检查材料和估计家族间差异；这个数不是统计充分性的保证。家族以词项、义项及模板依赖组织，换几个词或改几个句式不能自动增加独立家族数。确认阶段的规模由预定最小重要效应和先导不确定性决定，在确认输出前固定。

| 子实验 | 主要操纵 | 必须保持或另外核对的因素 |
|---|---|---|
| L 单独作用 | 固定词条信息，在配对查询中改变该义项是否适用；比较原义项呈现、匹配中性内容和无 L 基线 | 定义自身正确，查询中的词形可相同；原位中性替换和自然删除有不同含义，不能当作重复 |
| D 单独作用 | 明确的信息关系适用／不适用 × 关键词面重合高／低 | 各格示例自身的答案正确；使用少量正反例配对，匹配标签数量与位置；L 独立关闭 |
| D 标签诊断 | 在事先指定的对照上保持文本和标签总数，改变文本—标签对应 | 与“正确但不适用”条件分开，避免把不适用等同于错标签；变更确实影响对应关系 |
| L+D 关键组合 | 在以上关系已定义后，选预先规定的代表条件检查词典是否改变示例的作用 | L 不再由改变后的 D 自动重新生成；明确研究 L→query、L→demo 或二者，保留来源记录 |

示例的四格对比优先检验两个有辨别力的条件：**词面相近而信息不适用**、**词面不同而同一信息／规则适用**。四格之间要有明确的材料构造依据，不能以模型反应倒推所属格子。不同词形的词典条目若没有同义、别名或可见指代关系，不能强行标为“低重合但义项适用”；因此上述四格主要用于 D，不机械复制给所有 L 条件。

保留无证据基线及足以判断形式效应的中性对照，不将中性文本视为无心理作用的绝对零点。不把所有措辞、评分、探针、模型、任务再乘进所有条件。[Min 等](https://aclanthology.org/2022.emnlp-main.759/)在其研究范围内发现标签空间、输入分布和格式具有重要作用，支持拆解 D 的设计；其结果不能预先证明本项目示例标签无关。

材料可以沿用 AI 草拟、人类核对的既有方式，但审核不看目标模型输出，保留 AI 来源、整批采纳与逐项裁决的区别。参考 [HateCheck](https://aclanthology.org/2021.acl-long.4/) 和包含普通话的 [Multilingual HateCheck](https://aclanthology.org/2022.woah-1.15/)组织功能类别；不直接继承与本项目不一致的 hate 定义，不将模板测试的表现外推为自然数据总体表现。

**第三步：固定测量方式并做新家族确认。** 主协议先限定在一种固定输出设置。在开发材料上核验候选标签、实际 tokenizer 和答案边界，优先考虑对称的单 token 输出以减少长度因素；单 token 本身不消除标签偏好或映射学习负担。评分选择按事先明确的可测性原则决定，不能挑选最有利于既有结论的口径。保留少量预定映射敏感性检查，不把所有编码称为等价观察。

分别报告连续分数变化、参考一致性和双向分类变化、家族间异质性。适用性效应的预期方向应由具体对比确定，不统一要求向 non-hate 移动。恢复百分比留作内部实验的辅助量，目标接近零时不能让比例主导结论。数字超过浮点误差界不等于具有统计或功能重要性；无显著变化也不等于证据被完全忽略。若要支持“影响很小”，需预先定义实际等效范围并评估不确定性。

开发与确认按词项及模板依赖隔离；共享基础构造的材料不能跨两侧冒充独立。现有 discovery、8 条查询和 Q01 均是探索材料；旧 reserve、calibration 和历史 test 的访问边界不因本建议变化。新确认仅称“未参与本轮开发的家族”，不宣称模型预训练从未接触相关语言模式。确认材料不根据模型成败替换，统计按家族依赖聚合，不按提示数、候选数或重复 pass 增大样本量。

行为确认与内部确认还需分别登记暴露：若根据已看到的行为确认结果修改内部候选或判据，该集合就不能继续充当这次修改的未参与选择验证。可以在同一确认集开放前同时冻结行为判据和内部候选；若做不到，内部验证另用未参与选择的家族，不能通过重新命名恢复其独立身份。

在确认输出前写清楚不同结果导致的下一步：

| 结果 | 研究后续 |
|---|---|
| 适用关系在预定家族中有可重复影响，词面／标签对照不能充分解释 | 进入适用关系调节的有限内部验证 |
| 影响主要跟随词面与标签对应，在预定家族中重复 | 以这类证据误用为机制对象，不继续寻找预设的“正确适用性模块” |
| 多因素共同作用，方向随预定功能切片不同 | 限定具体条件下的混合机制，保留异质性 |
| 主要依赖输出编码 | 将结论限定为相应输出协议下的计算；编码本身成为待解释因素 |
| 效应小或家族间不一致，证据不足 | 报告目前无法建立所需现象；只补能区分明确解释的对照，不自动扩大内部扫描 |

**第四步：有条件地返回内部干预。** 内部实验应从上一步可重复的现象提出路径预测。MLP34 可与 block34、后层决策状态对照一起作为已有候选；候选身份不赋予它跨家族的语义功能，也不要求以后必选该模块。[activation patching 方法研究](https://arxiv.org/abs/2309.16042)显示指标和扰动构造会影响定位结果，因此应先固定将要检验的对比及解释范围。

供体设计应交叉适用关系和最终答案：加入相同答案、适用关系不同，以及答案不同、适用关系相同的情形；控制一般分类偏移，并检验正确证据条件是否受损。按基线 margin 匹配只能作诊断：它可能筛掉适用关系本身产生的效应，不足以证明剩余状态“纯粹表示适用性”。匹配规则须在开发阶段固定，保留未匹配结果，不能依据 patch 成败筛选供体。

先在开发家族定位并冻结候选，再在新家族检验同一位置和操作；恢复、破坏、无关状态及位置对照服务于具体主张。无须预设 attention 专管示例、MLP 专管词典，或必须找到单一模块。若只证明决策状态可转移，就保持这一结论。[Overthinking the Truth](https://proceedings.iclr.cc/paper_files/paper/2024/hash/bb63841e1ad12370a34504f15c60db4f-Abstract-Conference.html)已研究错误示例的后层影响；本项目值得检验的增量是正确材料在不适用语境中的迁移，以及它与简单标签跟随的关系，当前不能宣称已经建立该增量。

受控结果之后再返回固定 10 示例及原检索逻辑，检验对新案例的预测；通过这一步说明受控现象如何连接实际系统。小型受控实验不直接替代真实流水线的效果评价。

**资源优先级。** 暂停新一轮 Q01 层／头／神经元细化、残差联合路径扫描，以及把 Q05/Q03/Q04/3169 迁移当作主阶段；暂停在主现象未明确前全面扩大模型、group、路由器和词典修订。保留历史结果、原参考与审核参考、成熟评分工具及所有数值失败记录。

未来验证策略另立版本，把评分内核资格、每次新输入的覆盖检查和关键科学对比复核分开。已有重复及换卡为零不保证新长度、batch、后端或 hook 也稳定；新形状要做边界检查，新内部操作要做 hook/self-patch 检查。可以减少全矩阵机械重复，但不能直接删改旧冻结的 12-pass 规则或放宽容差。降低计算量的第一选择是减少不区分科学解释的条件，而非削弱必要核验。

**下一项具体交付。** 应形成一份短的竞争假设与判据表、一个跨词项的材料先导包，以及对应的主评分和确认划分方案。材料包先做到可审核、每个对比能说明“改变了什么、预期区分哪两种解释”；达到这一点后再冻结和执行小规模行为先导。当前评审完成的是优先级判断，不宣称该材料包、确认集或运行协议已经建立。

本建议涉及[现行主协议](general-model-ld-mechanism-protocol-v1.md)的阶段优先级调整：把 hate 和受控跨家族识别前置，完整 group、多模型及既有基准验证后置。主协议原先并不把新独立数据集泛化列为本阶段完成条件；新家族确认是针对拟提出的跨语境解释增加的证据要求，不能事后加到旧实验的验收标准上。所有旧冻结、选择器及人工字段保持历史身份，mechanism_ready 未改变。
