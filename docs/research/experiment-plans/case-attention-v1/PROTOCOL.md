## 工程资格与生命周期

模型及所有浮点计算 FP32、eager、batch 1、禁 TF32、无 KV cache、无量化或模型 CPU/disk offload；仅遥测张量复制到 CPU。新版本复用已固定的 native model loader，保留旧代码字节。UTF-8 I/O 显式启用。

每条输入执行：无 hook baseline、只读 capture、capture 重复、逆序、左 padding、右 padding，共 72 次。另 14 次边界截断前缀。所有 12 条进行 greedy 单字后原生 EOS 检查，首步复用原始参考向量，额外最多 84 次、通常 12 次。工程通过并正常释放后由显式 full 命令再做 12 条 production；生产前向与 capture 逐 token／层／头映射重放一致。

总上限 182 次 forward；若各条件均单字后 EOS，110 次。没有模型采样、不新增答案推理长链。每次完整词表向量、绝对注意力数组、producer、prompt/输入哈希均留存，可 CPU 重建资格。

预先固定验收值：

- 无 hook／只读 hook logits 完全相等；重复和逆序 margin 与 attention 差为 0。
- padding 的 margin 最大差 ≤0.001。前缀对照只比较匹配边界注意力，不把该边界 logits 当成最终答案。
- padding／前缀的注意力单元素差 ≤0.0001，单行 L1 差 ≤0.001；有效行概率和误差 ≤0.000002；未来位置严格为 0。
- 新 margin 工程界为 max(1e−6, 2×实测最大 margin 差)；片段 mass 界为 max(1e−7, 2×实测最大 attention 行 L1 差)。均不是统计置信区间。density 的界按对应可见长度分母传播。
- 全部 12 条须输出恰一个“有／无”随后 EOS；非法输出和失败保留，不据结果换输入、换分数、放宽门槛或自动重试。

GPU bind 与 run 仅后续显式执行：重新核验实际空闲 UUID、型号、显存和占用，绑定一张至少 44,000 MiB 的卡；源与完整权重哈希核验。CPU 准备复用已封存完整权重哈希、重验 metadata 和 shard size/mtime，不宣称重新读取过全部 16GB checkpoint。设备绑定与数值通过是独立的后续状态。

运行有独立目录、单 writer 锁、逐请求提交；STOP／SIGTERM 在请求边界暂停；只允许显式 paused resume 或 qualified→full。failed／complete 终态不可重启。所有复用记录检查身份与校验和，不吞掉损坏。正常退出及 owned worker 释放后，CPU 才允许读取独立 query reference 文件、加入分析与生成结果页面。
