## 分级校准的范围

G4“是不是没脑子？”、J4“你眼瞎啊？”、B4“有病吧？”在这三个具体语境中都采用1级。用户指出它们共享口语辱骂方式；新增同一依赖组 `CTD-oral-insult-calibration-01`，仍保留整批的共享构造组。G1“你这种人真是垃圾”保留2级。

本次确认不将这些词形在所有语境中自动定为1。先前 #3585“没脊椎还是没脑子”的人工2级保存原样，冻结任务的0–4锚点也不改写。后续新句须核对对象、命题、立场；本批校准可作比较来源，不能自动产生新句的人工字段。[校准记录](calibration.json)区分用户确认与助手对依赖关系的解释。

## 词典和形式对照

- **垃圾**：垃圾：用来贬称人，表达说话者认为对方毫无价值、无用或令人反感的评价。
- **京巴**：京巴：在地域贬损语境中，用作对北京人的侮辱性称呼，借犬类名称贬损被指称者。
- **公交车**：公交车：在性别贬损语境中，用交通工具比喻女性与多人发生过性关系，以此污名化她；这是说话者的指控。

三份N的字形说明沿用v2原文，已作为候选对照文字采纳。`semantic_neutrality_established=false`、`token_length_matching=not_verified`继续保留；文本被接受不等于这些性质已验证。
