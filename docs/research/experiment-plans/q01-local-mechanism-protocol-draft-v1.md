本轮目标限定为：哪些层／位置的内部状态，能传递 Q01 的词条 O→N1/N2 所引起的共同移动 C 和示例配对交互 I？这里的“传递”是固定输入对照上的局部干预作用，不预先称为义项选择、独立词形偏向、完整电路或纠错机制。

## 2. 两个方向、两条示例臂、两个目标

沿用 m＝score(non-hate)−score(hate)，原 JSON 标签无 EOS 总分为主口径。对每组 g=(F,N)，令 d_H=m(N_H)−m(O_H)，d_A=m(N_A)−m(O_A)，C=(d_H+d_A)/2，I=d_H−d_A。

在一个固定层／位置 S 上进行两种干预：

- **N→O：** 将 N_H 的状态放入 O_H、N_A 的状态放入 O_A，得到 r_H=m(O_H←h(N_H,S))−m(O_H)，r_A 同理。报告 R_C=(r_H+r_A)/2、R_I=r_H−r_A，分别与 C、I 比较。
- **O→N：** 将 O_H 的状态放入 N_H、O_A 的状态放入 N_A。为统一方向，定义 k_H=m(N_H)−m(N_H←h(O_H,S))，k_A 同理，报告 K_C=(k_H+k_A)/2、K_I=k_H−k_A。原始反向移动也完整保存，不能因使用 k 的符号约定而隐藏反向结果。

若内部状态传递了相应输入效应，希望 R_C/K_C 向正的 C 靠近，R_I/K_I 向负的 I 靠近。必须同时保存两条臂的原始 m、干预后 m、预测、r/k、C/I 残差及数值界。分数靠近 donor、恢复全部幅度和改变最终分类是三个不同结论。

例：两臂都增加约 10 分，说明 R_C 很大，但 R_I≈0，不能解释原来的示例差值变化。Q01 在 O 下的 δ 本来为正，因此 I<0 也不是通用的“负词语干扰增加”。

## 3. 建议的有限扫描范围

本地 Qwen3-8B 配置为 36 个 decoder block、4096 维隐藏状态。首轮建议使用 **block 索引 [0,5,10,15,20,25,30,34] 的完整 block 输出**，即 attention 与 MLP 均加回残差之后、下一层之前。这是 8 个预先指定深度，不是看热图后挑层。每次仅替换一个位置／注册 span 的完整向量，不缩放、不改范数、不加噪声。

建议 4 个主要位置，形成 32 个层×位置单元。以下为 CPU 已核对的真实 Q01 提示，全部使用零起点索引；F1/F2、O/N1/N2、H/A 各自内部均一致。

| 位置角色 | 原标签 | A/B 正反映射 | 用途 |
|---|---:|---:|---|
| 完整词条槽末端 token | 218 | 234 | 该槽末端是否传递词条条件差异 |
| 示例 3 输出末端 token | 415 | 427 | 词条差异是否出现在相关示例的状态中 |
| 查询“嘿嘿”的完整 token span | [730] | [732] | 查询关键表达处的局部状态 |
| 回答候选开始前的最后提示 token | 745 | 747 | 回答前汇总位置 |

原标签完整提示为 746 token，A/B 为 748 token；词条槽分别为闭区间 186–218、202–234。上述等长性不表示词条内部逐 token 意义对应。首轮用槽末端这个共同边界，不将 N1/N2 的某个内部词任意对应到“黑人”或“侮辱”。单个槽末端没有效果也不能排除整个词条的信息分散在其他位置。

正式材料应把语义角色、字符区间、token ID、token 区间、position ID、prompt hash、候选开始边界写入逐提示位置表。背景探针的回答前位置按自己的提示重新定位；不得复制真实 Q01 的绝对下标。只在相同标签编码内交换状态，禁止原标签与 A/B 的激活跨编码混用。

评分保持现有 full-sequence teacher forcing、FP32、eager attention、use_cache=False 及候选投影内核。donor 单独使用**不含查询候选答案的提示**采集；同一 donor 缓存用于 hate 和 non-hate 两个候选。受干预的 prompt 状态在各个候选评分中保持相同规则，不能复制任何答案 token 状态。保留当前模型普通文件副本、注册哈希与新鲜租约核验；新 hook 适配器另建版本，不修改已封存内核。

## 4. 先验收工具，再研究效应

正式实现至少准备以下检查；新 hook 的数值资格不能由上次 GPU 结果自动继承。

| 检查 | 必须看到的行为 |
|---|---|
| 无 hook 的历史重放 | 96 个来源提示及候选边界不变；新运行复现既有原始分数 |
| 只采集、无替换 | 采集操作不改变评分；缓存不含候选答案或 Gold 选择 |
| 同条件缓存原样写回 | 使用实际 prompt-only 缓存路径做 self-patch，评分与原条件一致；不能只测一个空 hook |
| 候选独立性 | 同一个提示位置的 donor 缓存身份与候选无关；在 full-sequence 与 prefix 校验中核对实际复用 |
| 完整差异 embedding 替换 | 在所有 O/N token 差异位置替换 embedding，应复现对应 donor 输入分数；这只是输入重建的工程正对照 |
| 相同前缀控制 | 替换发生在词条之前的同一位置，donor/recipient 前缀相同，预期不改变分数 |
| 末层不可传播位置 | 在 block 35 输出处替换查询“嘿嘿”等早于候选预测位置的 token，后面已无跨位置计算，预期不影响候选分数 |

还需核验重复、padding、prefix、候选顺序、不同物理 GPU，以及每种新增模块 hook 的输出结构和生命周期。异常时中止该新运行并定位原因，保留失败回执，不能通过放宽 epsilon 获取接受。

延续 epsilon＝0.0013427734375 作为待复核的旧数值界，并保持更严格的原参考／重复容差。原 m、原 C/R_C/K_C、原 I/R_I/K_I 的保守界分别为 epsilon、2epsilon、4epsilon；完整重校准 NCC 对应为 2epsilon、4epsilon、8epsilon。所有共享项先按物理评分身份合并系数再传播界，尤其 R−C 等残差不可把本可抵消的原分数重复计误差。以上是数值界，不是统计置信区间。

最终回答前的末层向量替换单列为输出端诊断。当前候选是多 token 字符串，仅改变首次预测位置并不保证重建整个标签序列的分数，也不能据此定位词条读取路径。

## 5. 原标签、NCC、A/B 的干预读数

原标签总分继续为主口径，均分和 EOS 辅助分数同时导出；两种 A/B 映射使用各自的 donor/recipient、完整提示和候选。三种编码的所有 32 个主要单元都保留结果，不在看到原标签热图后只复核最有利的映射。

NCC 必须拆清两个估计对象：

1. **固定背景的 NCC 干预读数。** 对受干预真实输入减去 recipient 原有背景 b。同一 recipient 的干预前后差值中 b 抵消，所以 R/K 的这类变化与原均分完全相同，只是固定背景下的读数，不是独立校准复现，也不应冒充改变整个条件后重算的 NCC。恢复目标和分母也使用同一 recipient 背景下的 O/N 差值，因而等于原均分目标；不能沿用表 1 中完整重校准 NCC 的 C/I 作为这一读数的恢复分母。
2. **同类干预后重新校准。** 对词条末端、示例答案末端、回答前位置，五个背景提示也有明确对应角色。分别使用同一 probe ID、同一词条方向的 donor/recipient 做干预，再按原规范重算五探针平均概率、背景 margin 和 NCC。保留原始背景变化、单探针和留一诊断。

查询“嘿嘿”的位置在空串／空格等背景中不存在。这一角色的完整重校准 NCC 标为不适用，保留固定背景读数；不能把真实 Q01 的状态塞进空背景，也不能事后改成背景末端位置。两类 NCC 分表解释，不能把不同估计对象混作一张统一恢复率排名。

若采用上面的 8 层×4 位置，并对所有单元进行双向、两臂、四组评分，主要科学矩阵包含：3 种真实编码的 32×4×2×2×3＝1536 个受干预提示，以及 3 个可重校准角色的 8×3×4×2×2×5＝1920 个背景提示，共 **6912 次候选评分**。这是一次主要评分的计算量；96 个来源提示的回归、donor 采集、工具检查、负对照、重复与换卡等另计，不能把 6912 当作完整 GPU 预算。正式冻结时需把完整调度逐项展开后再确定预算和设备分配。

## 6. 特异性控制及候选选择

同条件写回与词条前位置主要排查实现错误；它们不能代替语义或区域特异性控制。建议另列：

- 示例 9 的输出末端：原标签 673，A/B 676。它处在词条之后，也可能承载词条信息，所以不是预设严格为零的控制；若同样传递很大效应，降低对示例 3／查询位置特殊性的判断。
- N1↔N2 的双向同角色替换，保持 F/H/A/编码不变。两者都不含目标词条，作为中性填充差异的参照；N1/N2 的原始分数本就不同，不能假定该对照为零。记录输入差、激活差范数和输出变化，不进行未注册的范数缩放。

建议探索阶段不按“翻成 non-hate”挑位置。为后续细化预先登记一个保守的选择规则：对每个候选单元，分别检查 C 或 I；若四组的 R 与 K 均沿目标方向超过数值界，并使该目标的绝对残差相对零干预减小，才进入该目标的候选列表。所有原始曲线和未合格单元照常保存。

候选排名可使用四组、两方向中最小的 `1−abs(target−effect)/abs(target)`，原总分为选择口径；只有 denominator 在数值界外才给比例，同时保存未归一化值。比例不截断在 0–1。C、I 各最多保留一个单元，平局按层索引、既定位置顺序处理，重合则去重；A/B、NCC 及控制反向导致结论降级，不能换选另一个位置直到一致。

若进入下一层细化，只检验这至多两个单元的原层及相邻层，并分别替换 attention 输出和 MLP 输出，最多 12 个模块×位置单元，新增 hook 重新验收。首轮无合格单元则停止该定位范围并报告失败，不解释为模型没有相关机制；分散表示、多个组成部分共同作用及补偿都可能使单位置替换不充分。这个规则及后续范围在运行前仍需形成独立正式冻结。

## 7. 预先判读与最终目标的关系

| 结果 | 可以支持的结论 |
|---|---|
| C 恢复，I 不恢复 | 该状态影响共同分数移动，尚不能解释示例词语交互 |
| I 恢复，C 很小 | 该状态对局部交互有作用，尚不能解释整体判别偏移 |
| 两者双向恢复，四组和编码检查保持 | 支持所测层／位置对这组输入差异的局部中介作用 |
| 只有一个方向有效 | 记录方向不对称；不能单凭另一方向无效断言该组件无关 |
| 无关位置／N1↔N2 也有相似作用 | 需要保留通用状态替换或填充内容敏感性解释，不能声称目标角色独有 |
| 只有输出端有效，或映射／探针推翻 | 保留输出编码或测量敏感的局部结果，不升级为义项选择机制 |
| 冻结范围无效 | 该局部测试未定位到足够解释目标的状态，不继续无边界挑层／头 |

即使 Q01 成功，仍需在位置和读数冻结后，另用已暴露的 Q05、Q03/Q04 和原 3169 检查转移边界；共同向 non-hate 移动不能说明仍能识别应判 hate 的语境。这些例子已被看过，不称为新留出。原 reserve 继续按总计划的后续门槛处理。
