# 示例 D：第一批构造与审核草稿

**状态：新示例及新关系均为AI草稿，尚未人工采纳。** 查询来自[已冻结材料](../cross-term-materials-v1/frozen-01/README.md)。本次开始 D 单独作用：6条查询、16条新示例、8个正反示例包、30个候选条件；参考词典始终为空。

## 查询范围与构造目的

先选 G2/G4、J2/J4、B2/B4：三个普通所指的无攻击查询，以及三个含另一处口语辱骂的有攻击查询。沿用已采纳参考0/1级，不改查询正文。尚未覆盖G1/J1/B1和反对辱称的G3/J3/B3。

A包用普通所指场景中的“有／无另一处口语攻击”作正反配对。B包用“实施／反对指人隐喻辱称”作正反配对。这两类规则按具体位置审核，不能因都能导向有／无就认为完全相同，也不能由none宣称示例整体无效。

## 四类候选条件

| 条件 | 指定词形 | 示例内容 | 对每条查询的关系建议 |
|---|---|---|---|
| same_form_A | 出现研究词 | 普通所指＋口语攻击／普通表达 | 同分支示例rule_fit=direct；配对的另一分支=partial；词义信息direct。 |
| same_form_B | 出现研究词 | 指人辱称／反对这种辱称 | 指定贬损义与隐喻立场规则均不解释查询的普通所指，建议none。 |
| other_form_A | 不出现研究词 | 纸箱场景＋口语攻击／普通表达 | 具体名词信息none；同分支规则direct，另一分支partial。 |
| other_form_B | 不出现研究词 | 废物辱称／反对这种辱称 | 具体名词信息与所指定隐喻立场规则均建议none。 |

“同分支”指这六条查询中预先核对的两种结构：普通所指且无攻击，或普通所指伴随另一处口语攻击。它们在本批恰好分别对应无／有，但不能把“答案相同”推广为规则直接适用的依据。重点边按这种具体结构确定，不看模型输出，也不把整包合并为一个关系分数。每包始终是两个示例，顺序暂定有→无；另有D为空的基线。因此6×5=30个候选条件，其中6个基线桥接原L草案的Ø输入。

## 已知伴随变化与审核问题

本稿先让关系与配对可审核，**尚不能作为只改变规则适用性的干净因果对照**。A正例为1级、B正例为2级；A/B同时改变攻击强度、隐喻用法、作者立场结构和措辞。标签数量与位置一致只排除了其中一部分差异。正式比较前需要判断哪些伴随变化可接受，哪些要另加针对性对照；不以标签平衡掩盖差异。

A的四条不同正例都使用“有病吧”，B4查询也有这个短语；指定词形缺席不代表全文无重合。X的两对示例被六条查询复用。家族、模板和复用依赖都保留，不计成六套独立证据。未做token长度匹配或正反顺序诊断。

优先审核：（1）16条新示例是否自然且自身答案成立；（2）48条D→query边的具体信息、direct/partial/none及范围是否有依据；（3）12条L→demo候选边是否准确。新D关系的人工字段为空；L自身质量可复用刚冻结的同字节审核，但L→demo关系仍需新审。

## 比较与结果解释提案

每条查询保留四个D条件相对基线、同词／异词下的A−B、A／B内的同词−异词，以及交互，共54条表达式提案。主分数沿用m=z无−z有；另按已采纳答案乘+1（无）或−1（有）解释正确方向，不能要求所有查询统一向无移动。

若A在同词、异词条件下都更有利于正确方向，可作为具体规则迁移的候选现象，但先检查强度、结构和共同词句的解释；若效果主要随研究词形出现变化，保留词面关联解释。若有／无查询原始m同向整体移动，先检查类别偏置。变化很小时保留材料过易、冗余和敏感度不足等解释，不能直接宣布模型忽略示例。没有预定实际等效范围时，也不宣称无效应。所有条件均需保留，不能按结果选示例或改关系。

L+D组合不在这30个条件里。单独列出的L→demo边只为后续审核准备，`introduced_lexicon_relation_ids`及实际呈现记录均为空，不能据此认定模型看到了词典。
