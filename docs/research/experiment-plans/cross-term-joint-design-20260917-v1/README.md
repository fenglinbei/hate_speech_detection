## 本步作出的设计调整

原A/B示例包同时改变口语辱骂／指人辱称、1／2级强度及立场结构。保留它们的比较为**整包内容效果诊断**。主要组合对比固定查询和同一D包，再改变词典位置的内容；不把A−B解释为单独操纵“规则适用性”。

每个固定D下都比较：真实释义L、已采纳的字形说明N、空词典Ø。主分数仍是已冻结的m=z无−z有。L−Ø是加入这条具体资料的总输入效应，L−N是这两段具体文字的相对效应；N并非无作用零点，也未匹配token长度。

## 可审核的组合范围

| 查询的研究词用法 | 普通所指D_A | 指人辱称D_B |
|---|---|---|
| 指人辱称或反对该辱称：G1/G3、J1/J3、B1/B3 | L适用query，不适用demo | L两端都适用 |
| 普通所指：G2/G4、J2/J4、B2/B4 | L两端都不适用 | L适用demo，不适用query |

表中是义项关系建议，作者是否实施攻击另判；每行都包括有／无查询。L→query来自已采纳关系，L→demo仍需本轮审核。D→query分词义／所指与具体规则两维，不能从此表推成整包“有用／无用”。

每条查询有D空、同词A、同词B三个背景，分别配Ø/L/N：12×3×3=108条候选输入；另保留原稿6条查询的异词A/B、L为空的12条诊断，共**120条不同输入**。其中24条是真实L+D，另24条是N+D对照。旧L36条件和旧D30条件按6个重合基线合并为60条；新设计增加60条，不把别名重复计成独立输入或实验。

## 主要比较及解释范围

固定D后分别登记m(L,D)−m(Ø,D)、m(N,D)−m(Ø,D)、m(L,D)−m(N,D)，共108项。另与D为空时的相同差值比较，形成72项交互提案。它们说明**这个具体D包如何改变这条具体词典资料的影响**，并不证明抽象义项机制或排除所有长度、位置、措辞解释。

保留72项D整包诊断（含原54项），与上述比较分栏；共252项表达式提案，无模型结果。按查询参考解释正确方向：无乘+1，有乘−1。原始m、标签、方向及数值分辨性须分别保留。实际效应阈值和运行数值界仍需在执行前登记，不能从未资格化的小差异下结论。
