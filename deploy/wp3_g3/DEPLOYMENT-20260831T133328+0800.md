## Deployed fixes

The service still validates the complete immutable, content-addressed source
bundle and relation-review frame fail-closed during startup. Runtime bootstrap,
save, and mutation responses now reuse that validated in-memory frame. A save
continues to perform decision replay validation, owner-only session validation,
cross-process locking, CAS, canonical hashing, atomic replacement, and `fsync`,
but no longer replays the complete frozen artifact graph twice per autosave.

The browser now:

- suppresses save and confirm shortcuts while a save is in flight;
- avoids scheduling a duplicate save while awaiting an in-flight mutation;
- rebases a same-page queued mutation to the latest revision observed by that
  page immediately before sending it, while preserving genuine cross-page CAS;
- sends one random, anonymous `X-Review-Client-Instance` value per page load.

Nginx now emits JSON access records containing `$request_time`,
`$upstream_response_time`, `$request_id`, and the anonymous client-instance
header. It forwards `X-Request-ID` to the application and exposes the same ID
on responses. The application validates both observability headers before
logging them and records application `duration_ms`, request ID, and client
instance without logging the session token or decision body.
