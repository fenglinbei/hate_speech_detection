如何理解

每行是一层，列是原文中的参考片段。

注意力大小没有“有 / 无”的方向，也不等于对答案的因果贡献。

灰色或空白表示材料不可见、未提供或尚未加载，不代表测得零注意力。

质量使用整个可见上下文的分母，不会按筛选后的片段重新归一化。密度不可相加。

条件共享端点，不能当成独立确认。

平均与误差口径

36 层平均为等权算术平均。选择“全部头平均”时，再平均 32 个头。查询整体位置沿用原实验的位置平均定义。

片段汇总与层平均计算使用原始 FP64 数据。逐层 token 着色沿用 FP32 展示副本，平均 token 着色使用 FP64。数值界限是工程复现包络，不是统计置信区间。

换序比较会改变位置、距离和上下文；按材料和按槽位的对齐回答不同问题。
