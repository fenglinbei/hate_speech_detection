# 两轮注意力数据与 36 层平均

这一版在原有 `hsd.fenglin.pro` 静态网站中增量加入内容替换实验，并提供层平均视图。运行结果、审核记录、材料冻结及 GPU 执行代码均未修改。部署状态以本目录上一级的 `current.json` 和对应部署回执为准。

## 使用

- “实验轮次”保留首轮 12 个条件，增加内容替换实验的 88 个条件。默认仍为首轮；两个轮次的基线保持各自评分结果。
- 选择查询后，可按基线、答案、释义、正文与答案、同标签换序筛选新一轮条件。
- “36 层平均”显示片段条形分布，并可点击片段查看 32 个头的分布。读数支持总质量及每可见 token 平均，支持单头或全部头平均。
- 展开“片段范围与条件对比”可选择完整材料或正文／答案／释义、全部上下文、比较条件与读取位置、材料或槽位对齐、固定色标和排序。快捷按钮选择本轮同条件基线。
- 浏览器地址保留当前视图参数；两种视图均可导出带查询、读数、对比条件和色标说明的 SVG。页面另提供完整内容替换报告、88 输入表、258 比较及图表 PDF。

## 数值口径

对于每个头、读取位置和源 token，对封存的 FP64 注意力数组沿 36 层取等权算术平均。全部头模式再平均 32 个头。查询整体／焦点等读取位置继承原实验的位置平均定义。

片段总质量与密度从原始 FP64 汇总分别沿层轴平均。密度分母是各读取位置可见的片段 token 数均值。筛选参考材料不会重新归一化；父片段与子片段有重叠，不能跨层级相加。层平均可能掩盖层间差异，保留逐层图供对照。

差分为当前条件减对比条件；缺失或不可见的片段保留 NA。按材料和按槽位对齐有不同解释。注意力没有标签方向，不能直接当作因果贡献。这仍是两个已暴露案例，各比较共享端点。

## 数据与验证

旧结果来源 `reviews/case-attention-v1/results-01`，新结果来源 `reviews/case-content-replacement-v1/results-01`，报告来源 `report-02`。科学目录和所有源文件只读。

`build.py` 检查源清单、分层显示字节与原始 FP64 数组，并计算平均文件。100 个条件共核对 20,778,048 个平均 token 值；与逐层除以 36 后累加的独立实现最大差异为 3.8858e-16，片段平均重建最大差异为 4.4409e-16。

`audit_release.py` 独立比对全部 100 条完整输入与分数、原始片段汇总，重算 1,219,200 个层平均汇总值，并检查全部 3,387 个新文件及其 gzip。`check_browser.cjs` 在真实浏览器对照原始汇总验证 10,648 个展示值，涵盖两个轮次、逐层／平均、单头／全部头、质量／密度、可见性、读取位置差分、材料／槽位对齐、快速切换、Unicode 原文及 SVG。另验证网络错误重试、手机无页面横向溢出。

## 传输与缓存

旧发布的 912 个数据文件从现有版本硬链接继承，不重复上传。新增数据按条件加载元数据，原文按选定层加载 FP32 文件；平均原文只加载一个 FP64 平均文件。比较条件只取汇总，不加载其 token 权重。浏览器元数据缓存最多 4 个条件，每个条件最多 2 层及 1 份平均文件。

首个增量包为 2,707,671,040 字节。上传期间完成的浏览器布局修正通过独立 UI 小包记录，原大包保留；`package_ui_revision.py` 仅允许替换 HTML、JS、CSS，并保持全部科学资产记录不变。

## 上线与回退

`deploy.py stage` 检查当前配置、父版本和包摘要，校验全部继承与新增文件，写入独立版本目录。`activate` 再次核验后只替换 hsd 的静态 root，执行 `nginx -t` 和平滑 reload。失败自动恢复原 root。

登录凭据仅从标准输入传入，不写入包或日志，现有密码哈希保持不变。HTML、JSON、二进制平均与分层文件、gzip 和报告均继续受原有 HTTPS 登录保护。

切换前后比较两个审核会话、登录哈希、原审核服务与代码链接，以及 PDF 的配置、静态文件、进程／启动时间／重启次数和 HTTPS 响应。不得停止或重启审核、PDF 服务，不回滚用户记录。

需要回退时，先确认线上配置仍匹配该次部署回执，再恢复回执目录的 `previous-nginx.conf`，执行 `nginx -t` 后 reload Nginx。保留当前审核数据、所有旧发布目录和本轮科学结果；不重新运行 GPU 实验。
